# clawdbot 目标（工作目录：/Users/youfeini/Desktop/文档生成系统）
- 系统最终目标：
  在本仓库内完成“文档生成系统”的搭建：能够读取项目资料（招标文件/图纸/清单等）→ 在知识图谱/规则约束下生成结构化中间产物（JSON等）→ 自动导出可交付的施工组织设计文档（DOCX，后续可扩展图文并茂），形成可重复运行的端到端闭环。

- 当前卡点：
  Cursor 桌面端多个智能体经常等待人工输入/继续而停滞；改为由 agent CLI 在后台持续推进代码、脚本与验证，直到系统搭建完成。

- DoD（全部满足才算完成并停止）：
  1) 本仓库提供“一键运行入口”（脚本/Makefile/命令均可），无人工交互即可跑通一次端到端流程，并在 build/ 下产出结构化中间产物（JSON 等）。
  2) 导出环节可把结构化产物渲染为 DOCX，产物路径明确、可重复运行、无异常。
  3) 至少 1 个可重复执行的验证命令（pytest 或 scripts/*validate* 或 smoke test），对关键链路给出 PASS/FAIL，并在 audit.log 留证。
  4) README 或 docs/ 清晰写明：环境准备、启动命令、生成命令、产物路径、排错方式。
