# 施组专家系统 Professional v1.0.0（本地正式基线）

发布日期：2026-08-24
版本标识：`1.0.0-professional.local.20260824`

## 版本目标

本版本将当前本地施组专家系统整理为可验证、可提交、可回滚的正式使用基线。版本只固化源码、测试、受控知识资产与界面资源；用户上传资料、密钥、任务产物、缓存及可重建索引不进入版本库。

## 核心能力

- 18 个专业角色的受控编制、审查、证据、图表、排版与终审协作拓扑。
- 招标要求优先、项目事实账本、证据矩阵、规范适用性与冲突决策链。
- Anthropic 主链、OpenAI 备用链及本地只读预览能力；凭据由本机安全环境提供。
- 专业 Word 直接交付、结构质量检查、视觉渲染检查、空白页与稀疏页治理。
- 项目类型知识图谱、案例与图片参考增强，且不得覆盖招标、清单、图纸和答疑事实。
- 任务活动心跳、阶段状态、失败定位、交付回执与可审计诊断。
- 专业化 Streamlit 操作界面和 macOS 桌面启动入口。

## 版本边界

以下内容明确不纳入 Git：

- `.env.local` 等本机密钥配置；
- `backend/data/autoplan/v2/` 生成的 SQLite、索引和审计运行数据；
- 上传文件、任务目录、生成文档、日志、缓存和临时预览；
- 任何外部模型账号、额度或供应商状态。

## 验证门槛

正式版本提交前必须同时满足：

1. `git diff --check` 无格式错误；
2. Python 源码编译检查通过；
3. 完整后端测试通过；
4. 前端与后端本机健康检查通过；
5. 暂存区敏感信息和运行产物复核通过；
6. 提交后工作树保持干净，并保留提交前标签、版本标签和离线备份。

## 回滚设计

- 提交前基线使用带时间戳的 annotated Git 标签固化；
- 本版本使用独立 `codex/` 分支和 annotated 版本标签固化；
- 桌面离线备份同时保留全引用 bundle、tracked patch、untracked 压缩包、状态清单和 SHA-256 校验清单；
- 回滚优先使用新分支或新工作树检出标签，禁止通过破坏性命令覆盖现有用户文件。
