# 市政道路知识图谱通用增强层-V34.1

## 文件用途

本文件按《通用型知识图谱增强指令》对现有市政道路 V33.1 知识图谱进行增强，重点补充可检索、可推理、可评分、可审查、可整改、可复检、可导出能力。

本文件是 Knowledge 上传文件。它不替代 `01_市政道路工程知识图谱.md`、`02_市政道路接口与专项工程知识图谱.md`、`03_市政道路青天AI评标门控.md`，而是作为第 4 个增强层文件，用于提升 GPT Knowledge 命中能力和规则引擎化能力。

## 证据等级转换规则

| V34.1 证据等级 | 含义 | 使用边界 |
|---|---|---|
| A_primary | 招标、答疑、合同、图纸、清单、评分办法、规范、平台正式规则、用户指定准绳 | 可作为强制规则和冲突优先依据，但必须有 source、page/clause/evidence |
| A_secondary | 行业经验、常见评分项、常见施工措施、专家词库、通用写法 | 可增强召回和写作，不得覆盖 A_primary |
| A_pending | 待上传、待确认、待平台授权的规则占位 | 必须 source_required=true，不得虚构具体规则 |

项目级关键词权重规则:

| 来源/内容 | 权重等级 | 处理规则 |
|---|---|---|
| 答疑澄清、补遗变更关键词 | 最高权重 | 自动覆盖原招标文件旧关键词，标记高优先级 |
| 评分标准中的评分项和扣分项 | 最高权重 | 必须进入评分响应矩阵和章节标题 |
| 招标范围和工程量清单主要工程对象 | 高权重 | 必须进入工程对象关键词，不得泛化 |
| 图纸结构参数、材料规格、断面尺寸、施工范围 | 高权重 | 必须进入材料与参数关键词 |
| 技术标准和合同强制要求 | 高权重 | 必须进入质量、安全、验收控制 |
| 现场踏勘施工条件、风险点、交通和周边环境 | 中高权重 | 进入重难点、风险应对和总平面布置 |

| 空泛口号类词语 | 低权重或剔除 | “高度重视、科学组织、确保顺利、加强管理”等不得提升 |

施组编制调用规则:

1. 每个评分章节必须覆盖对应评分关键词。
2. 每个主要工程对象必须至少出现在工程概况、重点难点、施工方案、质量控制、安全控制、进度组织或总平面布置中。
3. 关键施工工艺必须写成“工序流程 + 操作措施 + 质量控制 + 验收标准 + 留痕资料”。
4. 风险关键词必须写成“风险识别 + 应对措施 + 检查频次 + 责任人 + 留痕资料”。
5. 材料和参数关键词必须写入材料控制、工艺控制或质量验收内容。
6. 答疑澄清关键词必须优先覆盖，禁止继续引用被澄清替代的旧内容。
7. 不得机械堆砌关键词，应自然嵌入施工措施、技术参数、检查动作和验收标准。
8. 对青天 AI 类人评标重点关注内容，强化项目对应性、评分项覆盖、参数化表达、工艺闭环、质量安全环保留痕。
