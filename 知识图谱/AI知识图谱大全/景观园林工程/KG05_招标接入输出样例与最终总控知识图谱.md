# KG05 招标接入、输出样例与最终总控（精简版）

## 招标接入流程

| 步骤 | 动作 | 输出 |
|---|---|---|
| 1 | 读取资料清单 | source_matrix：文件名、类型、页码、证明范围、禁止越界 |
| 2 | 抽取评分办法 | 评分项原文、分值、等级、满分关键词 |
| 3 | 建立关键词增强层 | 评分关键词、行业关键词、工艺关键词、风险关键词、质量/安全/绿色/智慧/验收/证据关键词 |
| 4 | 抽取否决条款 | 废标、响应性评审、技术标否决、资格商务隔离 |
| 5 | 抽取暗标规则 | 身份线索、文件属性、页眉页脚、图片、业绩人员 |
| 6 | 抽取格式规则 | 页数、字体、字号、目录、签章、上传命名 |
| 7 | 抽取工程范围 | 园林对象、接口专业、图纸清单、苗木表、设备表 |
| 8 | 绑定知识图谱 | 场景、对象、工序节点、V9 接口、术语、模板、满分候选规则 |
| 9 | 生成施组骨架 | 章节结构、评分项映射、关键词权重、正文模板、表格 |
| 10 | 审查整改复检 | 风险清单、语言替换、暗标扫描、冲突处理、证据留痕 |

## 标准正文段落

```text
本节针对“【评分项原文】”中关于【评分关键词】的要求进行响应。结合【证据来源】确认的【工程对象】，本方案以【目标任务】为控制目标，重点防控【风险难点】。实施时由【责任岗位/班组】按【工序流程】完成【具体措施】，配置【人员/机械/材料/检测资源】，按【控制标准/参数】进行过程控制。每道关键工序形成【记录名称】，由【检查责任人】复核；不满足要求时按【整改动作】闭环。
```

| 证据闭环 | 对象、措施、资源、参数、记录、blocker 完整 |

## 核心规则：关键词动态增强规则

规则名称：关键词动态增强规则（Project Keyword Dynamic Enhancement Rule）。

目标：每次录入新的项目资料包时，知识图谱不得只调用通用行业知识，必须自动读取该项目的招标文件、答疑澄清、补遗变更、工程量清单、图纸、技术标准和踏勘资料，动态生成“项目级关键词覆盖矩阵”，用于后续施工组织设计自动编制、内容审查、AI 评标匹配和得分优化。

### 触发条件

新项目创建或上传以下任一资料时自动触发：招标文件；答疑、澄清、补遗、变更文件；工程量清单；图纸、设计说明、勘察资料；现场踏勘图片、踏勘记录；技术标准和要求；评标办法或评分标准。

### 项目级关键词提取逻辑

| 关键词类别 | 提取内容 | 约束 |
|---|---|---|
| 项目基础关键词 | 项目名称、标段名称、项目编号、建设地点、招标人、工期、质量目标、合同估算价、最高投标限价、项目类别、标段划分 | 必须来自项目资料，不得沿用其他项目残留 |
| 评分关键词 | 评分项、分值、扣分项、页数限制、AI 辅助评审要求、综合评估法、技术评分合理价格法、施工组织设计、关键线路、施工总平面布置、质量保证措施、安全生产保证方案、水土保持、环境保护、安全度汛、冬雨季施工、重点难点 | 优先来自评标办法或评分标准，必须保留评分项原文 |
| 工程对象关键词 | 招标范围、清单子目、图纸构筑物和工程部位，如金属网兜抛石护岸、格网石笼、堤后盖重压渗平台、双轮铣防渗墙 | 不得只写“护岸工程”等泛化对象 |
| 施工工艺关键词 | 项目特有施工方法、工艺流程、机械设备、施工顺序、作业面组织、专项施工工艺、危大工程、关键技术路线 | 必须转化为工序流程、操作措施、质量控制、验收标准和留痕资料 |
| 材料与参数关键词 | 材料名称、规格型号、技术参数、工程量、强度指标、厚度、掺量、粒径、密实度、渗透系数、抗压强度、检测标准 | 必须写入材料控制、工艺控制或质量验收 |
| 风险控制关键词 | 临水作业、深基坑、高边坡、地下水、雨季施工、防汛度汛、交通导改、机械转场、临时用电、起重吊装、环保水保、扬尘控制、噪声控制、村庄农田保护、管线保护 | 必须写成风险识别、应对措施、检查频次、责任主体和留痕资料 |
| 验收检测关键词 | 测量复核、材料进场验收、见证取样、隐蔽验收、工序验收、单元工程验收、分部工程验收、单位工程验收、质量评定、检测频次、检测指标、资料归档、影像留痕 | 必须关联检测报告、验收记录、质量评定和资料归档 |
| 答疑澄清关键词 | 答疑、澄清、补遗、变更中修改后的评分标准、清单子目、工期、资格、材料、技术参数或报价要求 | 优先级高于原招标文件，标记为高优先级关键词并覆盖旧关键词 |

### 项目级关键词权重规则

| 来源/表达 | 权重 |
|---|---|
| 答疑澄清、补遗变更中出现并修改原要求的关键词 | 最高权重 |
| 评分标准中的评分项和扣分项 | 最高权重 |
| 招标范围和工程量清单中的主要工程对象 | 高权重 |
| 图纸中的结构参数、材料规格、断面尺寸、施工范围 | 高权重 |
| 技术标准和合同条款中的强制性要求 | 高权重 |
| 现场踏勘资料中反映的施工条件、风险点、交通条件、周边环境 | 中高权重 |
| 通用质量、安全、进度、环保管理词 | 普通权重 |
| 高度重视、科学组织、确保顺利、加强管理等空泛口号 | 低权重或剔除 |

### 项目级关键词覆盖矩阵字段

```markdown
| 关键词 | 关键词类别 | 来源文件 | 来源页码或条款号 | 对应工程部位 | 对应施组章节 | 推荐写入方式 | 权重等级 | 风险等级 | 是否为评分关键词 | 是否为答疑澄清覆盖关键词 | 是否必须在技术标正文中出现 | 建议出现频次 | 可关联的检测、验收、留痕资料 |
|---|---|---|---|---|---|---|---|---|---|---|---|---|---|
```

### 施组编制调用规则

1. 后续自动编制施工组织设计时，必须先调用项目级关键词覆盖矩阵。
2. 每个评分章节必须覆盖对应评分关键词。
3. 每个主要工程对象必须至少出现在工程概况、重点难点、施工方案、质量控制、安全控制、进度组织或总平面布置中。
4. 关键施工工艺必须写成“工序流程+操作措施+质量控制+验收标准+留痕资料”。
5. 风险关键词必须写成“风险识别+应对措施+检查频次+责任主体+留痕资料”。
6. 材料和参数关键词必须写入材料控制、工艺控制或质量验收内容。
7. 答疑澄清关键词必须优先覆盖，禁止继续引用被澄清替代的旧内容。
8. 不得机械堆砌关键词，应将关键词自然嵌入施工措施、技术参数、检查动作和验收标准中。
9. 对青天大模型 AI 类人评标重点关注的内容，应强化项目对应性、评分项覆盖、参数化表达、工艺闭环、质量安全环保留痕。

### AI 评标优化目标

施工组织设计最终应实现：评分项全覆盖；项目名称、工程部位、清单子目、图纸参数完全一致；施工措施具体、可执行、可检查；风险识别准确并对应现场；质量、安全、环保、进度均有量化指标；关键措施均有验收标准和资料留痕；避免通用模板化、空泛化、其他项目残留；提高青天大模型 AI 类人评标下的关键词命中率、响应完整度和技术标得分。
