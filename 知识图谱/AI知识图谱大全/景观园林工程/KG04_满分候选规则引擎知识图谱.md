# KG04 满分候选规则引擎（精简版）

## 目标边界

本文件用于生成青天大模型类人评标体系下的“满分候选”园林绿化施工组织设计。它不承诺必然满分；没有正式依据时，必须输出需补充或需人工复核。

## 证据等级

| 等级 | 适用内容 | 输出规则 |
|---|---|---|
| A_primary | 招标文件、答疑、合同、图纸、清单、评分办法、规范、平台正式规则 | 可作为强制响应和扣分判断依据 |
| A_secondary | 行业经验、常见评分项、通用施工措施、V9 清洁能力 | 只增强召回和写作，不覆盖正式依据 |
| A_pending | 暗标、页数、格式、签章、平台、地方规则等未上传规则 | 只能输出需补充/需人工复核 |

## 满分候选字段

| 字段 | 要求 |
|---|---|
| 评分项原文 | 必须保留，不得擅自改写 |
| 满分关键词 | 从评分项提取，不得编造 |
| 工程对象 | 绑定园林对象、接口对象或清单对象 |
| 施工措施 | 动作化、工序化、可执行 |
| 资源保障 | 人员、机械、材料、检测、养护 |
| 量化参数 | 来自招标、图纸、规范或项目资料 |
| 记录闭环 | 检测、验收、调试、移交、养护 |
| blocker | 缺证、缺参、缺界面必须显式列出 |
| closure_action | 指定补证、复核、整改动作 |

## 满分候选关键词字段

| 字段 | 关键词嵌入要求 | 权重位置 |
|---|---|---|
| 响应章节标题 | 包含评分关键词、工程对象、控制目标，如“海绵城市雨水花园竖向标高与通水验收控制” | 高 |
| 评分映射 | 原文提取满分关键词，补充行业关键词、重难点关键词、风险关键词 | 高 |
| 工序流程 | 嵌入关键工序、责任主体、检查频次、资源配置、动态优化 | 中高 |
| 质量标准 | 嵌入质量控制、参数标准、样板先行、隐蔽验收、检测报告 | 中高 |
| 安全绿色智慧 | 嵌入安全交底、风险闭环、扬尘噪声、节水节能、点位表、接口协议、联调记录 | 中高 |
| 验收证据 | 嵌入验收方法、整改复核、旁站记录、影像资料、移交清单 | 高 |
| blocker/closure_action | 嵌入缺资料、缺参数、缺授权、需补充、需人工复核、整改复查 | 高 |

## 规则占位

| 规则 | 未上传时默认处理 |
|---|---|
| 评分标准 | 停止确定性评分 |
| 暗标规则 | 默认按暗标谨慎 |
| 页数/字体/格式 | 输出需补充，不承诺合规 |
| 签章盖章 | 不替代人工检查 |
| 平台雷达检测 | 只输出风险提示 |
| AI 自动评审 | 无授权则需人工复核 |
| 废标/否决条款 | P0 人工复核 |

## 四步闭环正文结构

| 步骤 | 必写内容 |
|---|---|
| 目标任务 | 服务哪个评分项、解决哪个工程对象 |
| 风险难点 | 质量、安全、进度、接口、扣分风险 |
| 执行措施 | 谁做、做什么、怎么做、何时做、参数如何控制 |
| 验证检查 | 谁检查、用什么记录、如何验收、不合格怎么改 |

## 问题—措施—参数—验收—证据模板

```text
【问题】针对【评分项原文/评分关键词】中的【工程对象】要求，识别【风险难点/扣分风险】。
【措施】由【责任主体】按【关键工序/工艺流程】实施【控制措施】，配置【人员/机械/材料/检测资源】。
【参数】按【招标/图纸/规范/专项要求】控制【质量标准/参数标准/检查频次】；资料缺失时标注 blocker。
【验收】采用【验收方法】完成【进场验收/隐蔽验收/检测/调试/成活核验/移交验收】。
【证据】形成【旁站记录/检测报告/隐蔽验收单/影像资料/整改复核/移交清单】，不合格按【closure_action】闭环。
```

## 冲突处理

```text
答疑澄清中已修改条款 > 原招标文件旧条款
废标/否决条款 > 一般评分优化
暗标要求 > 普通排版习惯
项目专属要求 > 通用模板
A_primary > A_secondary > A_pending
无证据内容不得作为强制判断依据
```
