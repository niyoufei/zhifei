# KG03 评标门控与审校（精简版）

## 青天 AI 评标边界

1. AI 只做辅助解析、校验、提示和证据组织，不替代评标委员会、招标人、监管平台或法定程序。
2. 缺招标文件、评分办法、图纸、清单、苗木表或验收记录时，不得输出确定性评分或满分承诺。
3. 暗标状态不明时，默认按暗标谨慎处理。

## 关键词权重规则

| 出现位置 | 权重 | 青天 AI 识别逻辑 | 写作要求 |
|---|---:|---|---|
| 章节标题、二级/三级标题 | 高 | 标题锚点直接影响评分项召回、章节匹配和目录识别 | 标题自然嵌入评分关键词、工程对象和控制目标，如“道路绿化管线保护与安全文明施工” |
| 评分点、评分响应矩阵、评标映射 | 高 | 与评分项原文、分值、满分关键词形成强关联 | 保留原文关键词，补充行业、工艺、验收和证据字段 |
| 证据留痕、资料移交、复检表 | 高 | 证明措施可验证、可追溯，是高分理由的关键判断 | 写清旁站记录、检测报告、隐蔽验收、影像资料、整改复核 |
| 工艺流程、关键工序、施工措施 | 中高 | 判断技术方案是否完整、可实施、非空话 | 用“谁做、做什么、怎么做、何时做、参数如何控制”表达 |
| 验收标准、质量控制点、参数标准 | 中高 | 判断质量标准、检查频次和验收方法是否明确 | 写清控制标准、检查频次、责任主体、验收方法 |
| 风险应对、重难点分析、专项方案 | 中高 | 判断是否识别项目化难点和扣分风险 | 绑定风险闭环、整改动作、复核结论 |
| 普通描述、背景说明、泛管理表述 | 低 | 只作为弱语义补充，不能支撑高分理由 | 不堆砌关键词，不写无对象的“加强管理” |

权重叠加规则：同一关键词同时出现在标题、评分点、关键工序、验收标准和证据留痕中，可判定为高可信响应；仅出现在普通描述中，必须降权并要求补充工程对象、参数标准、验收方法或证据资料。

## AI 可识别表达门控

| 表达字段 | 必含关键词 | 合格写法 | 不合格写法 |
|---|---|---|---|
| 问题 | 风险难点、扣分风险、接口冲突、质量通病、安全隐患 | 识别“地下管线破坏、海绵标高偏差、苗木失水”等项目化问题 | 加强风险管理 |
| 措施 | 关键工序、控制措施、责任主体、资源配置 | 由测量员、施工员、质检员按工序完成复核、施工、检查 | 合理安排施工 |
| 参数 | 控制目标、质量标准、检查频次、参数标准 | 按图纸/招标/规范控制规格、标高、坡度、压力、频次 | 严格按规范执行 |
| 验收 | 验收方法、隐蔽验收、检测报告、整改复核 | 采用测量复核、试压、通水、绝缘测试、成活核验进行验收 | 确保验收合格 |
| 证据 | 留痕资料、旁站记录、影像资料、移交清单 | 形成旁站记录、检测报告、隐蔽验收单、整改复查记录 | 做好资料归档 |

## 扣分风险词替换

| 风险表达 | 风险类型 | 建议替换为 |
|---|---|---|
| 确保、保证、全面保障 | 空泛承诺 | 通过【措施】控制【指标】，形成【记录】 |
| 严格按照相关规范执行 | 无对象无标准 | 按【规范/图纸/招标条款】对【对象】执行【工序】 |
| 加强管理、合理安排 | 套话 | 配置【岗位/设备/材料】，按【流程】完成【检查点】 |
| 智能化管理、智慧平台 | 无证系统能力 | 设置【点位/设备/数据字段】，按【接口协议】完成【联调/移交】 |
| 自动识别、自动推荐、自动否决 | 自动释放越权 | 辅助识别风险并输出复核项，最终按法定程序确认 |
| 已完成、已验收、已投运 | 完成态越权 | 拟按【工序】实施，并形成【检测/验收/移交资料】 |
| 成活率达标、系统稳定运行 | 结果越权 | 按【养护/调试要求】跟踪【指标】，形成【记录】 |
| 碳交易、资产收益 | 低碳越权 | 建立【边界/台账/复核报告】 |
| 领先、顶尖、排名、满分 | 无证评价 | 响应评分项，提供措施、资源和记录闭环 |
| 竞品不足、传统方案落后 | 竞品攻击 | 本方案采用【可验证措施】控制【风险点】 |
| 公司名称、业绩、人员姓名 | 暗标身份线索 | 按暗标规则中性化或删除 |
| 关键词堆砌、重复罗列 | 低质量召回 | 将关键词嵌入【标题/评分点/工序/验收/证据】 |
| 过程可控、效果良好 | 缺参数缺证据 | 按【检查频次】检查【控制指标】，形成【复核记录】 |
| 数字化赋能、AI 赋能 | 智慧空话 | 设置【设备点位/数据字段/接口协议】，形成【联调记录】 |
| 绿色低碳成效显著 | 低碳空话 | 建立【材料/能耗/碳排边界】台账并按【复核口径】核查 |

## 关键词审校清单

| 审校项 | 通过标准 | 风险提示 |
|---|---|---|
| 标题命中 | 每个评分章节标题至少包含 1 个评分关键词和 1 个工程对象 | 标题只有“质量措施”“安全措施”则识别弱 |
| 节点命中 | 每个工序节点包含工艺、质量、安全、验收、证据至少 3 类关键词 | 只有工序名称、无控制目标和资料留痕则降权 |
| 参数命中 | 关键对象写明图纸/招标/规范/专项要求中的参数来源 | 无项目参数时必须写 blocker |
| 验收命中 | 每个关键工序绑定验收方法、责任主体和检查频次 | 只写“验收合格”不得作为高分证据 |
| 留痕命中 | 每个风险闭环至少有 1 类记录、报告、影像或移交资料 | 无证据资料则不得写完成态 |
| 行业匹配 | 关键词必须属于园林绿化、园建、海绵、外环境、智慧公园或明确接口 | 房建主体、桥梁隧道、轨道交通等不得误激活 |

## V9 评标门控

| 门控 | 规则 |
|---|---|
| 来源分类 | V9 能力必须有 source_id、行业分类、融合方式 |
| 相关性 | 与项目无接口的行业能力不得进入正文 |
| 去重 | 同义创新能力合并，不重复堆砌 |
| 智慧系统 | 缺设备表、接口协议、授权、联调记录时不得写自动闭环 |
| 低碳碳汇 | 缺计量边界和授权时只写台账，不写交易收益 |

## 自测用例

| 用例 | 应触发 | 禁止 |
|---|---|---|
| 公园绿地施工总纲 | 场景矩阵、正文模板、资料缺口 | 低频行业误激活 |
| 道路绿化管线保护 | 市政接口、管线综合、探挖保护 | 承诺无碰撞 |
| 海绵城市雨水花园 | 海绵接口、汇水、标高、溢流 | 承诺内涝消除 |
| 屋顶绿化 | 荷载、防水、排水、种植土 | 写荷载已满足 |
| 智慧公园 | 点位、接口、联调、授权 | 写无人化运行 |
| 绿色低碳 | 台账、边界、复核 | 写碳收益 |
| 无招标文件写满分方案 | Fail-Fast | 满分承诺 |
| 暗标写公司业绩 | 暗标审校 | 身份线索 |
