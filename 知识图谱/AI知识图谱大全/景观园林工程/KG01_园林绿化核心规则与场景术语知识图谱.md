# KG01 园林绿化核心规则（精简版）

## 核心定位

适用于园林绿化、公园绿地、道路绿化、海绵城市、滨水景观、外环境、厂区景观、屋顶绿化、智慧公园和绿色低碳示范项目的技术标生成与审校。

## 事实优先级

| 顺序 | 来源 |
|---|---|
| 1 | 招标文件、答疑、补遗、合同条款 |
| 2 | 评标办法、评分标准、暗标规则 |
| 3 | 图纸、设计说明、工程量清单、苗木表、设备表 |
| 4 | 规范、地方导则、监管要求 |
| 5 | 园林知识图谱和 V9 清洁融合索引 |
| 6 | 样本经验和模型推断 |

模型推断只能用于组织表达，不得替代项目事实、参数证据或验收记录。

## 正文模板规则

每个正文段落至少包含：

| 字段 | 要求 |
|---|---|
| 工程对象 | 苗木、铺装、管线、灯具、设施、构筑物等 |
| 工序动作 | 怎么施工、怎么检查、怎么交付 |
| 控制标准 | 图纸、招标、规范、验收或专项要求 |
| 资源配置 | 人员、设备、材料、检测或养护资源 |
| 记录闭环 | 进场、隐蔽、检测、调试、验收、移交、养护 |
| blocker | 缺资料、缺参数、缺记录时必须显式列出 |

## 核心术语

| 标准术语 | 同义词 | 禁止混用 |
|---|---|---|
| 园林绿化工程 | 景观绿化、绿化工程、景观园林 | 不等同全部市政或房建 |
| 园建工程 | 园路、广场、景墙、廊架、坐凳 | 不等同房建主体结构 |
| 绿化种植 | 苗木种植、植物栽植 | 不证明已成活 |
| 胸径 | DBH、胸径规格 | 不得与地径混用 |
| 地径 | 基径、地表直径 | 不得与胸径混用 |
| 雨水花园 | 生物滞留、生态滞留 | 不得与普通花坛混同 |
| 智慧公园 | 智慧园区、智慧运维 | 不得默认平台已接入 |
| 碳汇台账 | 植物碳汇、碳数据 | 不得写交易收益 |

## 禁止越界

1. 清单不证明已施工。
2. 图纸不证明已完成。
3. 规范不证明参数已确认。
4. 设备表不证明平台已接入。
5. 样本经验不证明本项目事实。
6. 缺验收记录不得写已验收、已投运、已移交。
