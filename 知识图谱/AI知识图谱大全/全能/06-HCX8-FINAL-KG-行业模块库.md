# 06-HCX8-FINAL-KG-行业模块库

## 文件定位

本文件是 HCX8-V21 最终上传包的行业知识模块库。用于在项目类别被招标文件、图纸、清单、设计说明、工程范围或用户明确资料激活后，补充工程对象、关键工序、评分关键词、质量安全环保控制、智慧绿色应用和验收资料候选。

行业模块只提供候选知识，不替代项目资料、专项方案、规范条文、设计参数或现场实测记录。未被项目资料激活的专业节点不得写成本项目确定事实。


行业模块使用规则：

1. 必须先识别项目类别和工程范围，再激活行业模块。
2. 多专业项目可同时激活多个行业模块，但必须按清单、图纸和界面划分对象。
3. 行业模块中的对象、工序、控制点和记录只能作为候选，需绑定项目证据。
4. 缺图纸、清单、专项设计或关键参数时，写 `需补充（缺：专业参数/工程对象证据）`。
5. 行业错配时触发 R1；例如市政道路项目写楼层主体结构，房建项目写桥梁挂篮施工。

## 01A 行业关键词增强字段

行业关键词必须自然嵌入评分点、工艺流程、重难点、风险控制、质量验收、安全文明、绿色施工、智慧建造和证据留痕，不得脱离行业对象机械堆砌。每个工序节点优先使用“问题—措施—参数—验收—证据”表达：

```text
针对【问题/风险】，在【工程对象/关键工序】中拟采取【控制措施】，按【参数标准/检查频次/责任主体】实施，通过【验收方法/检测报告/隐蔽验收/旁站记录/影像资料】形成证据留痕，并完成【整改复核/风险闭环/动态优化】。
```

## 10 多专业融合规则

多专业项目应建立对象界面矩阵：

```markdown
| 专业 | 工程对象 | 上游条件 | 下游交接 | 关键风险 | 记录/验收 | 需补资料 |
|---|---|---|---|---|---|---|
```

融合规则：

1. 房建加机电：重点处理预留预埋、管线综合、设备基础、吊顶内交叉、联动调试。
2. 市政加园林：重点处理道路排水、绿化带、海绵设施、交通导改和成品保护。
3. 水利加机电：重点处理闸泵设备、控制系统、单机调试、联动试运行和度汛。
4. 公路加桥梁：重点处理便道便桥、梁板预制架设、跨线保通和试验检测。
5. 装饰加机电：重点处理末端定位、检修口、消防联动、样板确认和成品保护。

## 11 行业错配雷达

| 风险信号 | 风险等级 | 修正动作 |
|---|---|---|
| 章节出现与项目类别明显不符的对象或工序 | R1 | 删除错配工序，改为项目资料激活对象 |
| 未给图纸清单却写专业参数、型号、厚度、跨度 | R1 | 改为 `需补充（缺：专业参数来源）` |
| 把行业候选记录写成已形成真实记录 | R1 | 降级为拟形成记录或需补充 |
| 多专业界面未说明上游下游交接 | R2 | 增加界面矩阵 |
| 只写行业概念，不写对象、动作、标准、记录 | R2 | 按四步闭环重写 |
