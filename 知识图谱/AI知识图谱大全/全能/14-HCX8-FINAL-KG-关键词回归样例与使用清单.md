# 14-HCX8-FINAL-KG-关键词回归样例与使用清单

## 文件定位

本文件是 HCX8-V21 最终上传包的 AI 评标关键词回归样例、模拟项目测试和定稿前使用清单。用于验证评分关键词是否在矩阵、标题、段首、正文、表格和收口中稳定命中，并检查是否存在关键词堆砌、漏项、证据缺口或压缩误删。

本文件只用于测试、审校和使用指导，不替代项目资料和评分标准。

## 01 使用场景

| 场景 | 使用方式 |
|---|---|
| 新建 GPT Knowledge 后 | 执行 P0/P1 关键词回归样例 |
| 上传新项目资料包后 | 先生成项目级关键词覆盖矩阵，再进入评分响应矩阵和正文 |
| 生成完整施组前 | 用关键词覆盖矩阵确认评分项原文和核心关键词 |
| 审校已有施组 | 用关键词自检发现标题弱、段首弱、表格弱、漏项 |
| 压缩页数后 | 用压缩保留清单确认关键词没有被删 |
| 最终定稿前 | 执行定稿前关键词清单 |

## 02 关键词回归通过标准

| 检查项 | 通过标准 |
|---|---|
| 评分项原文 | 每个评分项在矩阵中原文保留 |
| 项目级关键词矩阵 | 新项目资料包已生成项目级关键词覆盖矩阵，关键词均有来源文件、页码或条款 |
| 标题命中 | 高分值评分项标题包含原文或核心关键词 |
| 段首命中 | 每个评分项段首出现“本节响应招标文件……”或等效句式 |
| 正文闭环 | 关键词后接工程对象、动作、责任、频次、标准、记录 |
| 表格命中 | 关键评分项至少有一张表格字段承载证据 |
| 收口命中 | 最终收口列出关键词覆盖、自检、风险和补强动作 |
| 反堆砌 | 未出现连续堆叠关键词但无措施、无对象、无记录的段落 |

## 03A 反例坏样本审校

反例命中后必须输出“风险原因 + 修改后表达 + 需补资料”。命中 R0 停止最终化，未关闭 R1 不得输出最终版。

| 类型 | 坏样本 | 风险等级 | 修正方向 |
|---|---|---|---|
| 空话套话 | 高度重视、精心组织、确保万无一失 | R2 | 改为工程对象、控制措施、责任主体、检查频次、留痕资料 |
| 暗标泄露 | 我公司、本集团、类似获奖项目、项目经理姓名、Logo | R0 | 删除身份线索，改为投标人/承包人/项目部，必要时人工复核 |
| 完成态越权 | 已完成、已验收、已投运、已联调、已闭环 | R1 | 降级为拟实施、拟形成记录、待验收 |
| 参数虚构 | 准确率 95%、提升 30%、降低 80%、100% 合格 | R1 | 删除或标需补充参数来源、单位、检测方法、记录 |
| 行业错配 | 市政项目写主体封顶，房建项目写桥梁架梁 | R1 | 删除错配内容，改为已激活行业对象和工序 |
| 评分漏项 | 评分项有交通组织/BIM/成品保护但正文无标题命中 | R1/R2 | 新增矩阵行、章节标题、段首响应和闭环措施 |
| 异常低价 | 亏本让利、人员闲置、机械闲置、自有材料、类似业绩 | R0/R1 | 改为工程量、采购、资源、市场价格、成本证据链 |
| 自动释放越权 | 自动推荐、自动否决、AI 判定满分 | R0 | 无授权时只输出需人工复核 |
| 压缩误删 | 删除评分项原文、关键词矩阵、风险清单、验收记录 | R1/R2 | 恢复评分关键词、证据状态、验收闭环和 blocker |

反例审校输出：

```markdown
| 序号 | 命中反例 | 风险等级 | 原表达/缺口 | 风险原因 | 修改后表达 | 需补资料 | 是否阻断最终版 |
|---:|---|---|---|---|---|---|---|
```

## 08 使用提示词模板

### 生成完整施组

```text
请按 HCX8 知识图谱处理本项目。先解析招标资料并建立项目级关键词覆盖矩阵和评分响应矩阵，再输出 AI 评标关键词覆盖矩阵，确保每个评分项原文、核心关键词、项目工程对象、清单子目、图纸参数、标题命中、段首响应、正文闭环、表格证据和收口自检均可被稳定抽取。缺资料时保留需补充，不得编造。
```

### 上传新项目资料包

```text
请按关键词动态增强规则处理本项目资料包。先读取招标文件、答疑澄清、补遗变更、工程量清单、图纸、技术标准和踏勘资料，生成项目级关键词覆盖矩阵；矩阵需标注关键词类别、来源文件、来源页码或条款、工程部位、施组章节、写入方式、权重等级、风险等级、评分关键词标记、答疑覆盖标记、正文必现标记、建议频次和可关联检测验收留痕资料。完成矩阵后再进入评分响应矩阵和施工组织设计正文。
```

### 审校已有施组

```text
请按 HCX8 对该施组做 AI 评标关键词审校，重点检查评分项漏项、标题关键词弱、段首未响应、关键词堆砌、证据缺口、暗标身份、参数无来源、行业错配和压缩误删，并输出整改前后对照。
```

### 压缩页数

```text
请在压缩页数时保留所有评分项原文、核心关键词、实质性响应、工程对象、证据状态、验收闭环、暗标合规内容和 R0/R1 blocker，并输出压缩后的关键词自检。
```
