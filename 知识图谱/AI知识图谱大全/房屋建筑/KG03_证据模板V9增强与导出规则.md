## 3.1 关键词权重与证据留痕模板

关键词增强必须通过表格和正文双线落地。词表只负责召回，真正支撑评分的是标题锚点、评分点锚点、工艺锚点、验收锚点和证据锚点。

| 权重等级 | 出现位置 | 评标含义 | 留痕要求 |
|---|---|---|---|
| W5 高权重 | 章节标题、节点名称、评分项原文、最高档关键词、证据留痕字段 | AI 优先抽取并用于判断是否响应评分项 | 必须对应 TAB-SCORE-01、TAB-ANCHOR-01 或 TAB-FULL-BLDG-05 |
| W4 中高权重 | 工艺流程、控制措施、验收标准、参数标准、风险闭环 | 支撑完整性、针对性、可实施性 | 必须有责任主体、频次、标准、记录或检测报告 |
| W3 中权重 | 表格字段、资源配置、章节映射、重难点对策 | 支撑章节定位和高分理由反查 | 对应 Knowledge 节点、工程对象和表格记录 |
| W2 低权重 | 普通说明、背景描述、管理性衔接句 | 只作语义补充，不得单独作为高分依据 | 不作为释放门控依据 |
| W0 无效/降噪 | 非本行业、非本工程类别、范围外承诺、无来源确定参数 | 可能触发套用、越权或事实风险 | 删除、降级为需补充或改为配合接口 |

项目级动态增强输出要求：

1. 新项目资料包上传后，先生成 `TAB-PROJ-KEYWORD-01`，再生成评分响应矩阵和正文。
2. 答疑、澄清、补遗、变更优先级高于原招标文件、清单和图纸说明；发生修改时同步输出 `TAB-PROJ-OVERRIDE-01`。
3. 评分项、扣分项、页数限制、AI 辅助评审要求标记为最高权重 `W6`；招标范围、清单主项、图纸参数、技术强制要求标记为高权重 `W5`；踏勘风险和周边条件标记为中高权重 `W4`；通用管理词为 `W3`；空泛口号为 `W1` 或 `W0`。
4. 每个关键词必须追溯到来源文件、页码或条款；缺页码时使用“需补充页码/条款”，不得伪造。
5. 项目资料中出现非房建专用对象时，只作为项目级 A_primary 事实和工程对象使用，不迁入房建通用图谱。

输出模板示例：

```text
【章节标题】应包含评分项原词或专业节点名；【段首响应】说明评分要求和工程对象；【措施段】写关键工序、控制目标、责任主体、检查频次；【验收段】写验收方法、质量标准、整改复核；【证据段】写旁站记录、检测报告、隐蔽验收、影像资料和移交清单。
```

## 4. V9 候选增强原则

V9 只能作为 A_secondary 亮点启发，不得作为项目事实、设备承诺、强制参数、加分保证或暗标直接文本。涉及具体设备、平台、阈值、算法、接口、提前预警时间、节能降碳比例、二维码/区块链/云端留存能力时降为 A_pending。

启用前必须输出：

| V9/增强项 | 对应评分项/章节 | 工程对象 | 启用理由 | 证据状态 | 可写表达 | 禁用表达 | 需补充资料 |
|---|---|---|---|---|---|---|---|

证据状态：

1. 已证实：招标、图纸、清单、专项方案或设备资料明确要求。
2. 需补充：工程对象命中，但缺参数、点位、阈值、接口、调试或验收资料。
3. 仅建议配置：可作为亮点建议，但项目无明确要求。
4. 不适用：工程对象或承包范围不支持，不得进入正文。

## 6. V9 不迁入清单

| 范围外承诺 | 业主采购设备完整实施、运维收益、生产工艺达标 | 改为配合、预留、接口协调或需补充 |

## 7. 关系边类型

| relation_type | 含义 | 使用场景 |
|---|---|---|
| belongs_to | 属于某模块 | 工艺节点属于地基、主体、机电等模块 |
| maps_to_chapter | 映射章节 | 节点到 S 章节 |
| supports | 支撑评分项 | 节点到评分项族 |
| requires_response | 要求正文响应 | 评分项或规则要求具体措施 |
| constrained_by | 受规则约束 | V9 节点受降噪、暗标、边界约束 |
| verified_by | 通过表格或记录验证 | 节点到 TAB 表 |
| checked_by | 由审查节点检查 | 输出由暗标、雷同、V9、自检检查 |
| weighted_by | 由关键词权重规则赋权 | 关键词到标题、评分点、工艺、验收和证据位置 |
| embedded_in | 嵌入正文或表格字段 | 关键词到章节标题、节点名称、控制措施、资料留痕 |
| extracted_from | 从项目资料提取 | 项目关键词到招标、答疑、清单、图纸、踏勘、标准 |
| supersedes | 覆盖旧关键词或旧条款 | 答疑澄清、补遗变更覆盖原招标文件 |
| waits_for_source | 等待正式文件 | A_pending 规则占位 |
| overrides | 高优先级覆盖低优先级 | 答疑覆盖原招标文件 |
| rewritten_by | 由整改规则重写 | 空话套话改写 |

## 9. A_pending 占位规则

| 规则 | 需要补充文件 | 默认处理 |
|---|---|---|
| 评分标准 | 评标办法、技术标评分表 | 只用通用评分族，标注需补充 |
| 暗标规则 | 暗标条款、电子标制作说明 | 按最严通用暗标自检，不判合规 |
| 页数/字体/格式 | 投标文件格式要求 | 不承诺格式合规 |
| 签章上传 | 电子签章、上传平台规则 | 输出核对清单 |
| AI自动评审 | 平台说明、授权规则 | 不作自动评分结论 |
| 特殊专项参数 | 图纸、设备资料、专项方案 | 无参数不写确定值 |
| 废标/响应性条款 | 否决项、响应性评审表 | 输出需人工复核 |
