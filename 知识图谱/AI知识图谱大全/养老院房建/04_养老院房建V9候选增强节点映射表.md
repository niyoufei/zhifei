# 养老院房建V9候选增强节点映射表

用途：将通用房建 V9 候选素材降噪后，迁移为养老院房建可用的 BIM、智慧照护、绿色低碳、质量追溯、危大监测和运营移交增强节点。

## 一、融合原则

1. V9 候选素材只作为 A_secondary 增强素材，不能覆盖招标文件、图纸、消防审验、无障碍标准、运营需求和设备资料。
2. 缺少项目依据时，只能写“可根据项目要求配置”“拟预留接口”“需补充”，不得写成已配置、必然实现或确定加分。
3. 涉及视频监控、定位、健康数据、呼叫记录、老人个人信息时，必须同步写授权、权限、留痕、隐私边界和运营移交。
4. 智慧照护系统不得写成替代人工照护、自动医疗诊断、自动免责或保证不发生风险。
5. BIM、IoT、二维码、AI识别、能耗碳排等表达必须落到点位、数据项、验收方式、表格和移交成果。
6. V9 原文不得整段搬运，必须改写为本项目工程对象、部位、措施、频次、标准和记录。

关键词增强要求：

- 智慧建造关键词必须与养老院房建施工内容匹配，优先写 BIM深化、碰撞检查、房间一档、设备资产编码、二维码追溯、呼叫门禁点位、报警派单、权限配置、数据留痕、运维移交。
- 风险关键词必须同步出现隐私合规、平台能力边界、项目依据、可配置、不得替代人工照护、不得虚构消防/医疗/许可结论。
- 验收和证据留痕关键词必须落到点位验收、报警测试、联调记录、权限配置表、调试报告、检测报告、移交培训和整改复核。

## 四、不迁入清单

以下 V9 内容不得迁入养老院房建正文，除非项目 A_primary 资料明确要求：

| 禁迁内容 | 原因 | 可替代表达 |
|---|---|---|
| 已配置智慧养老平台 | 缺设备和平台依据易构成虚假承诺 | 可根据项目要求配置智慧照护点位和平台接口 |
| AI自动识别老人跌倒并自动处置 | 涉及隐私、误报、运营责任和医疗/护理边界 | 呼叫、视频或传感设备按设计调试，报警由运营人员处置 |
| 保证不发生跌倒、走失、噎食、烫伤 | 施工单位无法承诺运营结果 | 通过防滑、防烫、门禁、呼叫、标识和移交培训降低风险 |
| 已取得消防验收合格 | 消防验收属于法定程序结果 | 配合消防检测和验收，资料齐备后按主管部门要求办理 |
| 已取得食品经营许可或医疗机构资质 | 运营许可不属于施工事实 | 按设计完成厨房/医务用房施工接口和资料移交 |
| 护理人员配比或医护团队配置 | 属于运营组织，非施工事实 | 仅写施工交付条件和运营培训配合 |
| 固定床位数、房间数、护理等级 | 项目事实必须由招标或图纸证明 | 缺项写需补充 |
| 中心供氧或医用气体系统已配置 | 高敏感设备系统，需设计和资质依据 | 按设计设置或预留供氧/制氧设备接口 |
| 全面人脸识别、无感定位、健康数据采集 | 涉及个人信息和隐私边界 | 仅在项目要求下写授权、权限、留痕和移交 |
| 固定节能率、节水率、碳减排比例 | 缺计算边界和计量依据 | 建立能耗水耗和材料损耗台账，指标以项目要求为准 |

## 五、建议输出策略

| 输出场景 | 推荐策略 |
|---|---|
| 技术标正文 | 每个 V9 亮点压缩为 1 个工程化段落，并绑定表格 |
| 评分响应矩阵 | 将 V9 节点作为“增强节点”，不得替代基础工序 |
| 重难点章节 | 选取智慧照护、消防联动、无障碍体验复核、房间一档作为养老院亮点 |
| 质量创优 | 重点写适老化样板间、房间一档、设备资产追溯、室内空气复查 |
| 绿色施工 | 重点写老人敏感人群保护、室内空气、节能计量、垃圾分类和噪声控制 |
| 运营移交 | 重点写设备资料、调试记录、权限配置、培训和缺陷整改关闭 |

## 六、V9启用自检

启用 V9 节点前逐项检查：

1. 是否有项目依据或已标注“可根据项目要求配置”。
2. 是否绑定 `TAB-SEN-*` 或 `TAB-V9-*` 表格。
3. 是否避免医疗、护理、消防、许可和运营结果承诺。
4. 是否包含隐私合规和数据边界。
5. 是否改写为养老院对象、部位、措施、频次、标准和记录。
6. 是否通过暗标、雷同和项目残留检查。
