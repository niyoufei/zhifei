# KG01 公路工程核心专业知识图谱 上传版

## 用途
用于施工组织设计的专业对象、施工工序、质量安全环保进度控制、章节路由、关键词增强层和正文素材检索。公路工程为主模块，同时提供房建厂房、市政道路、水利水电、管网、园林绿化、高标准农田等行业差异化调用边界。它只提供专业知识、AI类人评标可识别表达和证据边界，不替代招标文件、评标办法、图纸、清单、规范和平台规则。

## 证据边界
清单证明范围和计价边界，不证明已施工。图纸证明设计要求和构造做法，不证明已完成。规范证明控制标准，不证明本项目参数已确认。试验、检测、调试、验收条目存在，不等于真实记录已经形成。缺项目资料时统一写“需补充”。

## 关键词增强层总则
关键词按评分点、行业对象、工艺节点、重难点、风险、质量控制、安全控制、绿色施工、智慧建造、验收、证据留痕和同义词簇组织。关键词必须嵌入章节标题、节点名称、工序说明、控制措施、参数标准、检查验收、风险应对、资料留痕、评标映射和输出模板示例，不单独堆砌。每个重要节点采用“问题—措施—参数—验收—证据”表达：说明评分关注的问题，绑定公路工程对象和关键工序，列出控制目标、质量标准、检查频次、责任主体、验收方法、留痕资料，形成风险闭环、整改复核和动态优化。

## 关键词嵌入位置要求
| 位置 | 嵌入方式 | AI评标识别目标 |
|---|---|---|
| 章节标题 | 标题含评分关键词、工程对象和控制主题，如“路面工程配合比与摊铺碾压质量控制” | 高权重命中评分项和章节路由 |
| 节点名称 | 节点含关键工序、质量标准或证据类型，如“试验段参数确认及压实检测报告” | 让AI抽取对象、工序和证据 |
| 工序说明 | 段首写问题、措施、参数、验收、证据 | 避免泛泛描述，提高专业判断权重 |
| 控制措施 | 写责任主体、检查频次、整改复核、动态优化 | 证明措施可实施、可检查 |
| 参数标准 | 写标准来源或“需补充标准版本/参数来源” | 避免无依据强结论 |
| 检查验收 | 写检测方法、验收方法、报告名称、复检条件 | 强化质量验收和闭环 |
| 资料留痕 | 写旁站记录、隐蔽验收、检测报告、影像资料、台账 | 提升证据链可追溯性 |
| 评标映射 | 写score_id、评分项原文、章节、对象、证据和风险闭环 | 支撑模拟评标和复检 |
| 输出模板示例 | 表格列名固定包含控制目标、关键工序、质量标准、检查频次、责任主体、验收方法、留痕资料、风险闭环 | 使正文、表格和复检口径一致 |

## 问题—措施—参数—验收—证据闭环模板
每个重要节点必须写成：控制目标、问题风险、关键工序、执行措施、参数标准、检查频次、责任主体、验收方法、留痕资料、整改复核。合格句式：针对【评分项原文/评分关键词】，本项目【工程对象】存在【重难点/风险点】，由【责任主体】在【工序节点】采用【工艺/设备/材料】按【标准来源或需补充来源】控制【参数/质量标准/安全控制/绿色施工指标】，通过【检查频次+检测/验收方法】形成【旁站记录/检测报告/隐蔽验收/影像资料/台账】，问题按【整改通知—责任落实—复检确认—资料归档】闭环关闭。
