# KG03 项目级评分解析模拟评标整改复检图谱 上传版

## 用途
用于用户上传具体项目资料后，把招标文件、评标办法、答疑、图纸、清单、规范、暗标和平台规则转化为A_primary项目级图谱，并驱动施组生成、模拟评标、整改卡、复检和放行。

## 项目级流程
| step | 输入 | 输出 | 阻断 |
|---|---|---|---|
| 资料登记 | 招标、评分、答疑、图纸、清单、规范、暗标 | 项目资料登记表 | 文件缺失或版本不明 |
| 关键词动态增强触发 | 新项目或新增招标、答疑澄清、补遗变更、清单、图纸、踏勘、技术标准、评标办法 | 项目级关键词覆盖矩阵 | 未读取项目资料包或仅调用通用知识 |
| 证据分级 | 来源、页码、条款、原文 | A_primary/A_secondary/A_pending | 无来源页码 |
| 评分项抽取 | 评分标准原文、分值、档位 | 评分项原文矩阵 | 缺评分办法 |
| 关键词增强 | 评分原文、高档词、同义词、工程对象、工序节点 | 关键词增强层和权重分布表 | 关键词脱离行业或无闭环 |
| 否决暗标解析 | 否决项、重大偏差、格式暗标 | 初评风险规则表 | 缺投标人须知 |
| 工程对象化 | 图纸、清单、合同范围 | 工程对象register | 缺图纸清单 |
| 章节任务书 | 评分矩阵、对象、专业节点 | S-01至S-17任务 | 章节缺映射 |
| 正文生成 | 任务书、闭环、证据 | 技术标正文候选 | P0 blocker未关 |
| 模拟评标 | 正文、评分矩阵、初评规则 | R0-R3风险表 | 缺评分原文 |
| 整改复检 | 风险表、整改卡 | 复检通过/补证/暂缓 | R3未关 |
| 终稿放行 | 复检结果、证据链 | 放行等级 | 关键A_primary缺失 |

## 关键词动态增强规则（Project Keyword Dynamic Enhancement Rule）
当新项目创建，或上传招标文件、答疑澄清、补遗变更、工程量清单、图纸设计说明、勘察资料、现场踏勘图片/记录、技术标准和要求、评标办法或评分标准任一资料时，必须自动触发项目级关键词动态增强。系统不得只调用通用行业知识，必须读取项目资料包并生成“项目级关键词覆盖矩阵”，用于施组自动编制、内容审查、AI评标匹配和得分优化。

| 提取类别 | 关键词来源与要求 | 施组调用要求 |
|---|---|---|
| 项目基础关键词 | 项目名称、标段名称、项目编号、建设地点、招标人、工期、质量目标、合同估算价、最高投标限价、项目类别、标段划分 | 写入工程概况、项目理解、响应总表，保持名称、标段、编号完全一致 |
| 评分关键词 | 技术文件评分标准、评分项、分值、扣分项、页数限制、AI辅助评审、综合评估法、技术评分合理价格法、施工组织设计、关键线路、总平面布置、质量、安全、水保环保、安全度汛、冬雨季施工、重点难点 | 每个评分章节必须覆盖对应评分关键词，章节标题、段首、评分响应矩阵和证据列同步出现 |
| 工程对象关键词 | 从招标范围、清单、图纸中提取具体工程对象，不得泛化；如资料出现“金属网兜抛石护岸、格网石笼、堤后盖重压渗平台、双轮铣防渗墙”等，应按具体对象写入 | 主要工程对象至少出现在工程概况、重难点、施工方案、质量控制、安全控制、进度组织或总平面布置 |
| 施工工艺关键词 | 项目特有施工方法、工艺流程、机械设备、施工顺序、作业面组织、专项工艺、危大工程、关键技术路线 | 写成“工序流程+操作措施+质量控制+验收标准+留痕资料” |
| 材料与参数关键词 | 材料名称、规格型号、技术参数、工程量、强度、厚度、掺量、粒径、密实度、渗透系数、抗压强度、检测标准 | 写入材料控制、工艺控制或质量验收，禁止无来源写死参数 |
| 风险控制关键词 | 临水作业、深基坑、高边坡、地下水、雨季施工、防汛度汛、交通导改、机械转场、临时用电、起重吊装、环保水保、扬尘噪声、村庄农田、管线保护 | 写成“风险识别+应对措施+检查频次+责任人+留痕资料” |
| 验收检测关键词 | 测量复核、材料进场验收、见证取样、隐蔽验收、工序验收、单元/分部/单位工程验收、质量评定、检测频次、检测指标、资料归档、影像留痕 | 绑定检测、验收、留痕资料，支撑AI评标可追溯判断 |
| 答疑澄清关键词 | 答疑、澄清、补遗、变更中修改评分标准、清单子目、工期、资格、材料、技术参数或报价要求的内容 | 优先覆盖原招标关键词，标记为高优先级关键词，禁止继续引用被替代旧内容 |

## 项目级关键词覆盖矩阵字段
关键词、关键词类别、来源文件、来源页码或条款号、对应工程部位、对应施组章节、推荐写入方式、权重等级、风险等级、是否为评分关键词、是否为答疑澄清覆盖关键词、是否必须在技术标正文中出现、建议出现频次、可关联的检测验收留痕资料。

## 项目级关键词权重规则
| 优先级 | 权重等级 | 关键词来源 |
|---|---|---|
| 1 | 最高权重 | 答疑澄清、补遗变更中出现并覆盖原文件的关键词 |
| 2 | 最高权重 | 评分标准中的评分项、分值项、扣分项、页数限制、AI辅助评审要求 |
| 3 | 高权重 | 招标范围中的主要工程对象、施工边界和专业范围 |
| 4 | 高权重 | 图纸中的结构参数、材料规格、断面尺寸、施工范围 |
| 5 | 高权重 | 工程量清单中的重点子目、工程量和计价边界 |
| 6 | 中高权重 | 技术标准和合同条款中的强制性要求 |
| 7 | 中高权重 | 现场踏勘资料反映的施工条件、风险点、交通条件、周边环境 |
| 8 | 普通权重 | 通用行业知识和通用质量、安全、进度、环保管理词 |
| 9 | 低权重或剔除 | 加强管理、严格落实、科学组织、确保质量、全面推进等空泛口号类词语 |

## 技术标准校核规则
编制到具体施工方案时，必须优先读取项目资料中的技术标准、图纸说明和招标技术要求。项目资料已明确参数的，以项目资料为准；项目资料未明确但确需补充标准参数的，优先检索知识库内现行有效规范；具备联网能力时，应检索官方或权威来源确认最新有效标准。无法确认来源的参数不得编造，应写“按设计文件及现行规范要求执行”，并标记“需核实”。不得为了增强专业感而虚构厚度、强度、间距、坡度、材料型号、检测频次、验收数值。

## 动态矩阵施组调用门控
后续编制施工组织设计必须调用项目级关键词覆盖矩阵。每个评分章节覆盖评分关键词；每个主要工程对象至少在工程概况、重点难点、施工方案、质量控制、安全控制、进度组织或总平面布置中出现；关键工艺写成工序流程、操作措施、质量控制、验收标准和留痕资料；风险关键词写成风险识别、应对措施、检查频次、责任人和留痕资料；材料参数写入材料控制、工艺控制或质量验收；答疑澄清关键词优先覆盖，禁止引用被澄清替代的旧内容；不得机械堆砌关键词，必须自然嵌入施工措施、技术参数、检查动作和验收标准。

## 风险等级
| 等级 | 含义 | 处理 | 终稿影响 |
|---|---|---|---|
| R0 | 未发现明显风险 | 保留 | 可放行 |
| R1 | 表达可优化 | 语言或章节微调 | 不阻断 |
| R2 | 资料或闭环不足 | 生成整改卡和补证清单 | 未关前为需补证稿 |
| R3 | 否决项、暗标、评分漏项、无依据强结论 | 必须整改复检 | 未关前不得放行 |

## 放行算法
缺评分标准原文时，尚不具备满分候选条件。缺图纸清单或专业边界时，满分候选需补证稿。存在R3否决、暗标、格式、身份线索风险时，尚不具备满分候选条件。评分项全覆盖、对象绑定、闭环、证据、语言、暗标均通过且P0/R3/R2关闭时，输出满分候选稿。放行等级不是评标结果承诺。
