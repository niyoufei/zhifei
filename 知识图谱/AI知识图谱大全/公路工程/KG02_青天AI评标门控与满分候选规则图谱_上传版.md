# KG02 青天AI评标门控与满分候选规则图谱 上传版

## 用途
用于安徽青天AI类人评标场景下的评分解析、初评避险、暗标审查、语言护栏、满分候选硬门控和终稿放行。它不承诺评标结果，只判断文本与证据链是否具备最高档响应条件。

## 青天AI评标理解
AI类人评标会抽取评分项、章节标题、响应句、工程对象、证据来源、措施闭环、风险和合规问题。施组必须让AI稳定判断：评分项是否覆盖，位置在哪里，是否结合本项目，措施是否可实施、可检查、可追溯，是否存在漏项、暗标、雷同、越权承诺或初评否决风险。

## 关键词权重规则
关键词权重按出现位置、证据强度和闭环完整度综合判断，不以简单词频替代专业响应。评分项原文、高档词、行业对象、关键工序、质量标准、检查频次、责任主体、验收方法、留痕资料同时出现时，视为高识别度响应。

| 出现位置 | 权重 | 命中规则 | 降权规则 |
|---|---|---|---|
| 章节标题、目录标题、表格标题 | 高权重 | 标题含评分关键词+工程对象+控制主题，如“路基试验段与压实检测质量控制” | 只有口号式标题、无正文闭环时降为中权重 |
| 评分项原文、评分响应矩阵、高档关键词列 | 高权重 | 保留评分项原文、分值/档位、高档词、同义词和映射章节 | 擅自改写评分项或漏页码时触发blocker |
| 证据留痕、验收闭环、整改复核列 | 高权重 | 出现旁站记录、检测报告、隐蔽验收、影像资料、台账、复检记录 | 只写“形成资料”但无资料名称时降权 |
| 工艺流程、关键工序、资源配置 | 中高权重 | 出现试验段、配合比、分层填筑、摊铺碾压、张拉压浆、单机调试、系统联调等 | 工序与工程对象不匹配时降权并隔离 |
| 参数标准、质量标准、检查频次 | 中高权重 | 写明标准来源、参数来源、检测频次或“需补充标准版本/参数来源” | 无来源写死参数、承诺固定达标时触发R2/R3 |
| 风险应对、安全文明、绿色施工、智慧建造 | 中权重 | 风险点、措施、责任主体、预警复核、整改闭环完整 | 仅写管理口号或固定收益时降权 |
| 普通描述、背景介绍、泛化管理语句 | 低权重 | 仅作补充说明，不作为满分候选核心依据 | 重复堆砌关键词、空话套话、无对象无证据时清洗 |

## 关键词增强识别逻辑
| 识别维度 | 高识别表达 | 低识别表达 |
|---|---|---|
| 评分响应 | 针对评分项原文，列出控制目标、关键工序、质量标准、检查频次、责任主体、验收方法、留痕资料 | 仅重复“科学合理、措施完善、针对性强” |
| 工程对象 | 路基、路面、桥涵、隧道、交安机电、保通迁改等对象由图纸、清单或评分项激活 | 未确认项目范围却写全部专业已实施 |
| 工艺措施 | 试验段、配合比、分层填筑、温度控制、张拉压浆、系统联调等与对象匹配 | 工艺词脱离章节或与行业不匹配 |
| 验收证据 | 检测报告、旁站记录、隐蔽验收、影像资料、整改复核、台账归档 | “确保合格、全部达标、一次验收通过” |
| 风险闭环 | 问题识别、整改通知、责任落实、复检确认、动态优化 | 只写“加强管理、严格落实” |

## 硬门控
| gate_id | 门控 | 通过要求 | 未通过处理 |
|---|---|---|---|
| FULL-01 | 评分项原文覆盖 | 评分项、分值、档位、关键词、页码完整 | 需补充评分标准，不定稿 |
| FULL-02 | 最高档语义拆解 | 科学、合理、完整、针对性拆成对象、措施、参数、记录 | 返回评分矩阵补写 |
| FULL-03 | 工程对象绑定 | 每项措施绑定路基、路面、桥涵、交安机电等对象 | 改为需补充或不适用 |
| FULL-04 | 四步闭环 | 目标、风险、措施、检查、证据输出齐全 | 生成整改卡 |
| FULL-05 | 参数标准来源 | 参数、频次、标准版本有来源或占位 | 写需补充标准版本/参数来源 |
| FULL-06 | 记录留痕 | 每项关键措施有记录、报告、台账或验收表 | 补证据输出列 |
| FULL-07 | 章节路由一致 | 评分矩阵、目录、正文位置一致 | 重新路由章节 |
| FULL-08 | V9清洗激活 | 删除原生噪声，证据激活后进入正文 | 未清洗不得进入正文 |
| FULL-09 | 暗标初评合规 | 无身份线索、格式风险、否决项风险 | 需人工复核 |
| FULL-10 | 平台规则闭合 | 平台、雷达、AI授权规则明确或占位 | 禁止自动评标结论 |
| FULL-11 | 语言密度 | 无空话套话，句式含对象、动作、检查、记录 | 调用语言护栏重写 |
| FULL-12 | 终稿放行 | P0/R3风险关闭，证据链可追溯 | 输出补证稿或暂不具备 |
| FULL-13 | 关键词增强层 | 标题、评分点、工艺、验收、留痕中均有自然嵌入 | 补写关键词映射和节点闭环 |
| FULL-14 | 权重分布 | 高权重词出现在标题、评分矩阵、证据留痕，不只在普通描述中出现 | 调整章节标题、表格列和证据列 |
| FULL-15 | 同义词归一 | 评分常用表达、近义词、行业词归一路由到S-01至S-17 | 更新同义词路由并复检漏项 |

## 初评和否决项优先级
否决项、重大偏差、响应性评审、暗标规则、格式上传、签章盖章、页数限制优先于评分优化。缺正式规则时，输出A_pending占位，不得自行判断合规。

## 暗标规则
暗标技术标不得出现投标人名称、简称、Logo、商标、人员姓名、证书编号、联系方式、地址、邮箱、网址、企业荣誉、特定业绩、专属工法、专属系统、单位归属线索。统一使用“投标人、承包人、项目部”。检查页眉页脚、图片水印、图签、文件属性、表格脚注、文件名、压缩包名称。

## 语言护栏
禁用或限制：加强管理、高度重视、确保质量、严格落实、做好保障、完善措施、提高效率、有序推进、认真执行、经验丰富、精心组织。替换为：由【岗位】对【对象】在【时间/工序】实施【动作】，按【标准/参数】检查，形成【记录】，不合格按【流程】整改复核。

## AI可识别表达模板
| 场景 | 推荐表达 |
|---|---|
| 评分点响应 | 针对【评分项原文/高档关键词】，在【响应章节】设置【章节标题关键词】，将【工程对象】、【关键工序】、【控制目标】和【证据留痕】纳入评分响应矩阵。 |
| 工艺流程 | 【责任主体】在【工序节点】按【工艺流程】控制【参数标准/质量标准】，检查频次为【来源确认或需补充】，形成【检查记录/检测报告/台账】。 |
| 重难点风险 | 【风险问题】影响【质量/安全/进度/环保/保通】，采取【技术措施+组织措施】，经【验收方法】复核，整改状态进入【风险闭环】。 |
| 质量验收 | 关键工序完成后按【标准来源】进行【检测/隐蔽验收/交工检测】，资料包括【旁站记录、检测报告、影像资料、验收表】。 |
| 智慧建造 | BIM、智慧工地、4D进度、安全识别、碳台账等只写【数据来源、预警规则、人工复核、整改闭环】，不得写自动评分、固定收益或完成态。 |

## 评分响应矩阵
| 字段 | 要求 |
|---|---|
| 评分项原文 | 保留原文或近似关键词，不自行改写 |
| 分值/档位 | 来自评标办法 |
| 满分关键词 | 最高档描述中的关键词 |
| 招标证据 | 文件、页码、条款 |
| 工程对象 | 清单、图纸、范围激活的对象 |
| 响应章节 | S-01至S-17 |
| 施工措施 | 人员、机械、材料、工艺、流程 |
| 资源保障 | 班组、设备、材料供应、检测资源 |
| 验收闭环 | 检查、检测、记录、整改、复检 |
| blocker | 缺资料、暗标、否决项、证据不足 |

## 冲突处理
A_primary优先于A_secondary；答疑澄清优先于被修改的原招标文件；项目专属要求优先于模板；暗标规则优先于普通排版；否决项优先于评分优化；无证据内容不得作为强制判断。发现冲突时输出冲突节点、冲突内容、来源、采用内容、覆盖内容、处理理由、是否需补文件。

## 放行等级
满分候选稿：评分项全覆盖、工程对象绑定、四步闭环、参数证据、暗标初评、语言密度、V9清洗、P0/R3风险全部关闭。满分候选需补证稿：正文和矩阵完整，但仍缺A_pending规则或参数来源。尚不具备满分候选条件：缺评分标准、关键图纸清单、暗标规则，或存在否决项、R3风险、重大证据冲突。
