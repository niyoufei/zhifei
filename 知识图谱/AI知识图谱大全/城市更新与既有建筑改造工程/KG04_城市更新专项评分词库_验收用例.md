# KG04 城市更新专项评分词库与 GPT 验收用例

## 用途

本文件用于防止施工组织设计退化为普通房建或普通市政套版，负责城市更新专项评分召回、章节映射、扣分风险反向审校和 GPT 配置验收。

## 关键词嵌入位置验收

| 嵌入位置 | 验收标准 |
|---|---|
| 章节标题 | 至少出现评分关键词、工程对象和验收或留痕词，标题不得只写“质量措施”“安全措施”。 |
| 节点名称 | 至少出现行业关键词、工艺关键词和风险或重难点关键词。 |
| 工序说明 | 必须写关键工序、责任主体、参数来源和检查频次。 |
| 控制措施 | 必须覆盖质量控制、安全控制、绿色施工或智慧建造中与本工程匹配的内容。 |
| 参数标准 | 必须标明来自图纸、规范、设备表、专项方案或待补资料，不得自拟数值。 |
| 检查验收 | 必须出现检验批、隐蔽验收、检测报告、试验记录、调试记录、移交清单等适用词。 |
| 风险应对 | 必须有风险触发、整改动作、责任主体、复核节点和 close_action。 |
| 资料留痕 | 必须区分拟形成记录、已提供证据、需补充资料，留痕词优先进入表格字段。 |
| 评标映射 | 必须保留评分项原文、满分关键词、AI识别词和同义近义词，不得替换招标评分项。 |
| 输出模板示例 | 必须采用问题、措施、参数、验收、证据五段表达。 |

## 关键词权重映射

| 位置 | 权重 | 复检动作 |
|---|---|---|
| 标题中出现 | 高权重 | 检查标题是否包含评分关键词、工程对象和验收留痕词。 |
| 评分点中出现 | 高权重 | 检查评分响应矩阵是否保留评分项原文并配置满分关键词、AI识别词。 |
| 证据留痕中出现 | 高权重 | 检查检测报告、旁站记录、隐蔽验收、影像资料、整改复核是否与措施对应。 |
| 工艺流程中出现 | 中高权重 | 检查关键工序、责任主体、参数来源、检查频次是否完整。 |
| 验收标准中出现 | 中高权重 | 检查验收方法、质量标准、检验批、试验记录或调试记录是否可追溯。 |
| 风险应对中出现 | 中权重 | 检查风险触发、纠偏措施、整改复核和 close_action 是否闭环。 |
| 仅普通描述中出现 | 低权重 | 不作为高分理由，要求改写进标题、矩阵、工序、验收或留痕字段。 |

## 扣分风险反向词库

| 风险 | 触发表达 | 修正 |
|---|---|---|
| 低密度套话 | 加强管理、严格落实、确保质量、合理安排、有效措施 | 改为岗位、动作、频次、标准、记录 |
| 证据越权 | 已验收、已投运、稳定运行、全部满足 | 改为拟形成记录或需补充 |
| 满分承诺 | 保证满分、必得满分、完全满分覆盖 | 改为最大化满分概率和逐项闭环 |
| 暗标风险 | 单位名称、业绩奖项、人员归属、联系方式、专属口号 | 清理并人工复核 |
| 异常低价无效理由 | 亏本让利、材料自有、机械闲置、人员闲置、类似业绩 | 删除并改为成本证据框架 |
| 自动释放越权 | 自动否决、自动推荐、无需人工复核 | 改为风险提示和人工复核 |
| 项目残留 | 其他项目名称、道路名、楼栋号、单位名称、行业错配工序 | 删除或按本项目证据重写 |

## 城市更新专项自检

最终输出前逐项检查：

1. 是否有评分项原文矩阵。
2. 是否召回城市更新专项，不退化为普通工程套话。
3. 是否有既有建筑调查鉴定和结构安全前置。
4. 是否有居民通行、扰民控制和周边协调闭环。
5. 是否有老旧管线、室外配套、雨污分流或产权接口说明。
6. 是否有外立面、屋面防水、公共部位样板和隐蔽验收。
7. 是否有消防、机电、弱电和联动调试闭环。
8. 涉及智慧社区时，是否有隐私、权限、日志、平台验收和运维移交。
9. 是否有危大、安全文明、绿色环保和固废处置记录。
10. 是否有竣工资料、培训、移交、保修和运维台账。
11. 是否清理低密度套话、暗标身份线索、异常低价禁用理由和自动释放越权。
12. 是否列出未关闭 blocker 与 close_action。
13. 是否建立关键词增强层，并覆盖评分、行业、工艺、重难点、风险、质量、安全、绿色、智慧、验收、证据留痕和同义近义词。
14. 关键词是否分布在标题、节点名称、工序说明、控制措施、参数标准、检查验收、风险应对、资料留痕、评标映射和输出模板示例中。
15. 是否按关键词权重规则复检，避免关键词只出现在普通描述中。

## GPT 配置验收用例

配置 GPT 后至少运行以下 12 个测试：

| 用例 | 输入 | 预期 |
|---|---|---|
| 资料不足 | 没有招标文件，直接写满分施组 | 输出需补充，不编造评分项 |
| 满分请求 | 保证青天评标满分 | 改为最大化满分概率，不承诺实际满分 |
| 暗标身份 | 暗标中写企业获奖和业绩 | 输出身份线索清理和人工复核 |
| 四步闭环 | 写外立面修缮质量措施 | 有目标、风险、措施、检查和记录 |
| V9 样本 | 把石化高风险作业能力写入项目 | 行业分类、证据降级、需项目边界 |
| 套话整改 | 优化“加强管理、确保质量” | 改成岗位、动作、参数、频次和记录 |
| 劳动力 | 人数你自己估 | 输出输入表，不编造人数 |
| 消防机电 | 消防弱电已稳定运行 | 缺记录时写拟形成，不写已稳定运行 |
| 居民扰动 | 老旧小区不停住改造安全文明 | 覆盖通行、消防、噪声、扬尘、投诉 |
| 整改复检 | 审校施组并给替换文本 | 输出风险、重写文本、复检和 close_action |
| 智慧社区 | 写高空抛物和人脸门禁亮点 | 先确认范围，补隐私、权限、日志、平台验收 |
| 运维移交 | 后期服务怎么写加分 | 输出资料清单、培训、保修、运维台账 |
| 关键词权重 | 标题没有评分词，只在段落末尾堆关键词 | 改为标题、评分矩阵、工序、验收、留痕多点嵌入 |
| 证据留痕 | 措施很多但没有记录资料 | 补旁站记录、检测报告、隐蔽验收、影像资料、整改复核或 close_action |
