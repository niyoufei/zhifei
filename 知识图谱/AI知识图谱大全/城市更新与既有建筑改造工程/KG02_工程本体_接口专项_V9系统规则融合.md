# KG02 工程本体、接口专项、V9 与系统规则融合

## 用途

本文件用于给施工组织设计提供城市更新与既有建筑改造工程的专业对象、接口关系、行业能力路由、术语字典、劳动力和写作规则。所有内容都必须受 KG01 证据边界约束。

## 城市更新核心工程对象

| 专业对象 | 重点内容 | 必要证据 |
|---|---|---|
| 既有建筑调查鉴定 | 现状调查、缺陷台账、安全鉴定、结构复核、荷载复核 | 检测鉴定报告、图纸、缺陷清单 |
| 保护性拆改 | 分区拆除、临时支撑、成品保护、居民通行、扬尘噪声 | 拆改图、专项方案、审批、监测 |
| 结构加固 | 粘钢、碳纤维、植筋、裂缝修补、构件置换 | 加固设计、材料证明、检测报告 |
| 外立面与屋面 | 外墙修缮、保温、涂料、幕墙、防水、渗漏治理 | 立面图、防水做法、材料复验、试验记录 |
| 公共部位装修 | 楼道、门厅、栏杆、地坪、无障碍、成品保护 | 装修图、样板验收、材料证明 |

| 室外市政 | 道路恢复、雨污分流、管线迁改、燃气、供热、通信、景观 | 管线图、产权确认、迁改方案、试压验收 |
| 智慧社区 | 门禁、监控、高空抛物、停车、充电、物联、平台接入 | 招标范围、点位表、权限规则、日志、平台验收 |

## 工程对象关键词增强层

每个工程对象必须生成一条关键词增强记录，字段为：

`专业对象 | 评分关键词 | 行业关键词 | 工艺关键词 | 重难点关键词 | 风险关键词 | 质量控制关键词 | 安全控制关键词 | 绿色施工关键词 | 智慧建造关键词 | 验收关键词 | 证据留痕关键词 | 同义近义词 | 适用边界`

|---|---|

| 结构加固 | 嵌入粘钢、碳纤维、植筋、裂缝修补、构件置换、基层处理；质量写材料复验、胶黏剂配比、锚固深度、固化养护、拉拔检测、隐蔽验收。 |
| 外立面与屋面 | 嵌入外墙修缮、空鼓排查、保温修复、涂料施工、泛水节点、防水附加层、蓄水或淋水试验；证据写基层验收、材料复验、节点照片、试验记录。 |
| 公共部位装修 | 嵌入楼道、门厅、栏杆、地坪、无障碍、消防疏散、成品保护；控制写样板先行、基层检查、允许偏差、居民通行安全和检验批验收。 |
| 消防机电弱电 | 嵌入消火栓、报警、喷淋、应急照明、防排烟、给排水、电气、暖通、管综、联动；证据写设备表、点位表、联动矩阵、单机调试、系统联调和消防验收资料。 |
| 室外市政 | 嵌入管线探测、产权确认、雨污分流、燃气供热、通信迁改、道路恢复、闭水试验、试压记录；风险写停复供、交叉开挖、防汛和居民通行。 |
| 智慧社区 | 嵌入门禁、监控、高空抛物、停车、充电、物联、平台接入、权限日志、隐私告知；边界写仅招标确认后释放，证据写点位表、网络供电、权限规则、日志和平台验收。 |
| 竣工移交运维 | 嵌入竣工图、设备资料、检测验收、培训交底、保修响应、运维台账；证据写移交清单、培训签到、设备说明书、质保文件和整改复核单。 |

项目级工程对象必须优先来自招标范围、工程量清单和图纸，不得用通用行业名称替代清单子目。若资料中出现“金属网兜抛石护岸、格网石笼、堤后盖重压渗平台、双轮铣防渗墙”等细分对象，施组标题、重点难点、施工方案、质量验收和证据留痕应使用细分对象；“护岸工程”等泛化词只能作为上位分类。

## 工序节点关键词增强层

工序级节点必须按“问题—措施—参数—验收—证据”写法生成，禁止只写管理口号。

`节点名称 | 评分关键词 | 工序说明 | 控制目标 | 风险点 | 控制措施 | 参数标准 | 检查频次 | 责任主体 | 验收方法 | 留痕资料 | 同义近义词`

| 节点名称 | 问题与风险关键词 | 措施与参数关键词 | 验收与证据关键词 | 同义近义词 |
|---|---|---|---|---|
| 现状调查与安全鉴定节点 | 既有结构不确定、缺陷遗漏、荷载复核不足 | 分栋分层调查、缺陷台账、检测布点、结构复核、荷载复核 | 检测鉴定报告、缺陷照片、复核记录、整改销项 | 查勘/踏勘/核查，鉴定/检测/复核 |
| 保护性拆改与临时支撑节点 | 误拆、扰动主体、临边坠落、扬尘噪声 | 分区拆除、临时支撑、保留构件保护、荷载控制、湿法作业 | 专项审批、技术交底、旁站记录、监测记录、影像资料 | 拆改/拆除/拆卸，支撑/支护/加固 |
| 植筋粘钢碳纤维加固节点 | 基层不实、锚固不足、材料失效、隐蔽漏验 | 基层处理、孔深孔径、注胶饱满、材料复验、固化养护 | 拉拔检测、隐蔽验收、材料复验报告、检验批记录 | 加固/补强/增强，复验/复检/抽检 |
| 外立面修缮与高处作业节点 | 空鼓脱落、渗漏复发、高处坠落、吊篮风险 | 空鼓排查、基层验收、节点加强、保温修复、吊篮验收 | 淋水试验、隐蔽验收、吊篮验收、旁站记录、整改复检 | 修缮/维修/修复，淋水/喷淋/冲淋 |
| 屋面防水节点 | 基层含水率、搭接不足、泛水薄弱、渗漏 | 基层处理、附加层、卷材搭接、女儿墙泛水、成品保护 | 蓄水试验、闭水记录、隐蔽验收、节点照片 | 防水/止水/抗渗，蓄水/闭水/试水 |
| 管线探测迁改节点 | 管线不明、产权不清、停复供扰民、交叉破坏 | 物探复核、产权确认、探沟验证、迁改顺序、停复供计划 | 管线探测报告、产权确认单、试压记录、交接记录 | 探测/探查/物探，迁改/改迁/移位 |
| 雨污分流与排水恢复节点 | 错接混接、倒坡积水、井室渗漏、防汛风险 | 接驳复核、坡度控制、井室改造、临排导流、防汛巡查 | 闭水试验、通水试验、CCTV检测、井室验收 | 雨污分流/清污分流，闭水/严密性试验 |
| 消防机电管综联调节点 | 界面不清、管线碰撞、联动失败、资料缺口 | 接口矩阵、管综协调、单机调试、系统联调、停复供计划 | 联动矩阵、调试记录、消防验收、移交清单 | 联调/调试/试运行，管综/综合管线 |
| 智慧社区点位平台节点 | 范围未确认、点位偏差、隐私合规、日志缺失 | 点位复核、网络供电、权限分级、隐私告知、平台接入 | 点位表、权限规则、日志记录、平台验收、运维台账 | 智慧社区/智能化/物联，日志/记录/台账 |

## 接口治理

所有跨专业接口必须绑定合同界面、图纸会审、接口责任矩阵、综合管线或接口图、调试验收记录和移交责任。设备存在不等于联动完成，平台存在不等于运维移交完成。

| 接口 | 控制重点 | blocker |
|---|---|---|
| 结构与拆改加固 | 鉴定、设计复核、临时支撑、监测预警、审批 | 缺鉴定不得释放拆改或加固结论 |
| 消防与机电弱电 | 停复供、管综、联动逻辑、单机调试、系统联调 | 缺联动矩阵不得写联动完成 |
| 装饰与防水 | 样板、基层验收、节点加强、隐蔽验收、成品保护 | 缺样板和参数不得写确定做法 |
| 市政外线 | 管线探测、产权确认、迁改顺序、试压闭水、道路恢复 | 产权不清不得释放接口责任 |
| 智慧社区 | 范围确认、点位、网络、供电、权限、隐私、平台验收 | 缺范围点位不得写项目包含 |

## V9 全行业融合路由

V9 只作为二级行业样本、接口风险和证据字段来源。不得把 V9 中的自动化能力、数字孪生、反欺诈、硬锁、熔断、加分承诺写成项目已具备能力。

| 行业类别 | 路由用途 |
|---|---|
| 房建、加固、防水、幕墙、钢结构、装饰、装配式 | 既有建筑本体、围护、装饰和结构更新 |
| 危大、拆除、基坑、脚手架、吊装、起重 | 安全文明、专项审批、监测预警 |
| 市政道路、排水、燃气、供热、管廊、海绵 | 室外配套、管线迁改、道路恢复 |
| 机电、消防、暖通、给排水、弱电、通信 | 消防机电接口、联动调试、移交 |
| 智慧社区、智慧工地、物联网、平台感知 | 智慧专项、权限日志、平台验收 |
| BIM、CIM、数字资产、智慧运维 | 资料归档、资产台账、运维移交 |
| 绿色、环保、固废、碳核算、园林 | 环境保护、绿色施工、资源化 |
| 电力、供热、储能、低碳能源 | 供能接口、停复供、安全许可 |
| 石化、工业管道、动火、焊口、防腐 | 高风险作业许可和安全控制候选方法 |
| 公路、轨道、铁路、机场、港航 | 保通、不停运、交通组织候选方法 |
| 水利、河道、防汛、生态、涉水 | 防汛、涉水施工、生态约束候选方法 |

## 通用底座与行业模块

通用底座统一包含评分项解析、项目级关键词动态增强、参数化表达、证据链、暗标避险、雷同避险、自检复检和资料不足提示。行业模块仅在项目证据匹配时释放，不得跨行业错套。

| 行业模块 | 必须保留的差异化工程对象 | 典型工艺与验收留痕 |
|---|---|---|
| 房建厂房 | 主体结构、钢结构或装配式、屋面防水、装饰装修、机电安装、消防联动、室外配套 | 测量放线、模板钢筋混凝土、钢构吊装、防水蓄淋水、机电调试、消防联动、检验批、隐蔽验收、检测报告 |
| 市政道路 | 路基、基层、面层、排水、交通组织、管线保护、道路恢复 | 压实度、弯沉、厚度、平整度、闭水试验、交通导改、管线探测、试验检测、分项验收 |
| 水利水电 | 堤防、护岸、防渗墙、导流、度汛、水保环保、单元工程验收 | 围堰导流、金属网兜抛石护岸、格网石笼、双轮铣防渗墙、压渗平台、度汛预案、单元工程质量评定 |
| 管网工程 | 沟槽、支护、降排水、管道安装、闭水或试压、回填压实、井室施工 | 沟槽验收、基础处理、接口连接、闭水试压、回填分层压实、井室砌筑或预制安装、影像留痕 |
| 园林绿化 | 土壤改良、苗木栽植、养护、灌溉、成活率、景观恢复 | 土壤检测、苗木检疫、种植穴、支撑固定、浇灌养护、成活率验收、养护台账 |
| 高标准农田 | 土地平整、灌排沟渠、田间道路、涵闸、泵站、农田防护 | 方格网测量、田块平整、渠系衬砌、涵闸安装、泵站调试、道路压实、农田防护、单项验收 |

技术标准调用规则：具体方案优先采用项目资料中的技术标准、图纸说明和招标技术要求；项目资料明确参数时不得擅自替换。资料未明确但需要标准参数时，优先使用知识库内现行有效规范；具备联网条件时检索官方或权威来源。无法确认的厚度、强度、间距、坡度、材料型号、检测频次和验收数值不得编造，应写“按设计文件及现行规范要求执行”，并标记“需核实”。

释放状态：

`candidate` 仅候选方法；`needs_project_evidence` 需项目证据确认；`project_usable` 证据确认后可纳入技术措施。

必需字段：

`source_alias | industry_category | target_node | dedupe_key | project_evidence | blocker | close_action | release_status`

## 行业类别关键词释放边界

V9 行业关键词只能按本表释放。与城市更新、老旧小区改造、既有建筑改造无项目证据关系的关键词，不进入标题和评分点，只能作为风险提示、候选方法或行业错配反向审校词。

| 行业类别 | 可释放关键词 | 释放位置 | 不得越权内容 |
|---|---|---|---|
| 房建、加固、防水、幕墙、钢结构、装饰 | 既有建筑、修缮改造、结构加固、外立面、屋面防水、公共部位、样板先行、隐蔽验收 | 标题、评分点、工序、质量验收、证据留痕 | 不得写新建主体结构完成、超出图纸的扩建改建结论。 |
| 危大、拆除、脚手架、吊篮、起重 | 危大工程、保护性拆改、临时支撑、专项方案、专家论证、监测预警、安全交底 | 安全文明、风险控制、工序说明、旁站记录 | 未经项目证据不得写已审批、已论证、已验收。 |
| 市政道路、排水、燃气、供热、通信 | 管线探测、产权确认、雨污分流、停复供计划、试压闭水、道路恢复 | 室外配套、施工部署、质量验收、移交资料 | 不得替代产权单位意见或确认无风险停供。 |
| 机电、消防、暖通、给排水、弱电 | 消防机电、管综协调、接口矩阵、单机调试、系统联调、验收移交 | 机电消防专项、接口治理、调试验收、资料留痕 | 设备存在不等于联动完成，平台存在不等于验收完成。 |
| 智慧社区、智慧工地、物联网 | 门禁、监控、高空抛物、停车充电、点位表、权限日志、平台验收 | 智慧专项、隐私合规、运维移交、证据留痕 | 招标未确认范围时不得写项目包含或已接入平台。 |
| BIM、CIM、数字资产、智慧运维 | BIM管综、数字化交付、资产台账、运维台账、竣工资料归档 | 资料归档、接口协调、运维移交 | 不得写数字孪生、自动优化、平台能力已具备，除非有明确证据。 |
| 绿色、环保、固废、园林 | 绿色施工、扬尘噪声、湿法作业、垃圾分类、密闭清运、消纳证明 | 安全文明、绿色施工、环保记录 | 不得写碳核算成果、绿色认证成果，除非招标或审批明确要求。 |
| 电力、供热、低碳能源 | 供能接口、停复供、安全许可、临时用电、交接记录 | 接口风险、停复供计划、安全许可 | 不得写储能、低碳能源系统建设内容，除非项目范围包含。 |
| 石化、工业管道、焊口、防腐 | 动火许可、焊接安全、防腐质量作为高风险作业候选方法 | 仅限候选方法、风险提示或行业错配审校 | 不得写成老旧小区核心工序，不得进入标题和评分点。 |
| 公路、轨道、铁路、机场、港航 | 保通、不停运、交通组织作为类比方法 | 仅限交通组织候选方法 | 不得写轨道、机场、港航专业施工能力为本项目内容。 |
| 水利、河道、防汛、生态、涉水 | 防汛排水、涉水保护、生态约束作为候选方法 | 防汛、临排、环保风险 | 不得写水利主体工程或河道治理内容，除非招标范围明确。 |

## 系统规则与术语门控

术语冲突时，以招标文件、最终答疑、现行规范和审批文件为准。

| 术语 | 使用边界 |
|---|---|
| 改造 | 对既有建筑安全性、功能完整性和性能提升进行改善，不当然改变结构体系和规模 |
| 改建 | 局部拆除重建，或使用性质、结构体系改变 |
| 扩建 | 扩大既有建筑规模或体量 |
| 新建 | 新建构筑物，或原建构筑物全部拆除后重新建设 |
| 修缮/维修 | 恢复或保持既有功能，不等于新增建设规模 |
| 加固 | 对可靠性不足或需提高可靠度的承重结构和构件采取增强措施 |
| 鉴定 | 判定建筑物性能状态的行为，不等于未检测部位均安全 |

## 劳动力和资源门控

适用安徽房建与市政项目时，资源计划须绑定：

`工程类别 | 规模等级 | 施工阶段 | 工人总数 | 工种 | 人数 | 技能等级 | 证书编号 | 有效期 | 实名制记录`

缺项目造价、规模、阶段、工人总数、证书台账时，不得输出确定性人数、证书数量或上岗结论。

资源计划字段：

`资源类型 | 工种/设备/材料 | 数量来源 | 计划数量 | 进场节点 | 责任岗位 | 验收/校验方式 | 证书或合格证明 | blocker | close_action`

## 写作护栏

施工组织设计段落必须回答：

`现场怎么干 | 用什么干 | 干到什么标准 | 谁来检查 | 检查频次是多少 | 形成什么记录 | 不合格如何整改复核`

工序级字段：

`工序名称 | 评分关键词 | 行业关键词 | 工艺关键词 | 风险点 | 操作步骤 | 设备/材料 | 关键技术参数 | 控制措施 | 检查频次 | 验证方法 | 证据留痕 | 责任岗位`

禁用低密度表达：按照要求执行、符合要求、确保、保障、严格落实、加强管理、相关规范、有关规定、现场实际情况、合理安排、有效措施。必须改写为岗位、动作、频次、参数、记录和复检。

## 交付规则

所有城市更新专项必须形成：资料来源、工程对象、控制措施、责任岗位、检查频次、记录表单、验收移交、blocker 和 close_action。未形成闭环的内容不得作为高分理由。
