# KG04 暗标雷达、评标模拟与最终交付图谱

## 文件用途

本文件用于 GPT 在生成或审校市政给排水厂站施工组织设计时，执行青天 AI 类人评标模拟、暗标身份线索扫描、雷同模板残留检查、评分项反向补写和提交前一键体检。

## 初步评审避险

不得出现：

1. 漏写实质性响应。
2. 工期、质量、安全、缺陷责任期、保修、节点目标与招标不一致。
3. 项目名称、标段、地点、招标人、建设内容、工程规模错误。
4. 其他项目残留。
5. 暗标身份信息泄露。
6. 格式、页数、字体、行距、目录、图表不符合要求。
7. 明显复制、同错、雷同、模板套话。
8. 降低或改变设计方案、技术工艺、施工标准。
9. 用亏本让利、人员闲置、机械闲置、材料自有、类似业绩解释异常低价。
10. 把计划实施写成已完成、已验收、已投运。
11. 把图纸、清单、招标要求写成已施工事实。

## 暗标雷达

暗标未确认前按最高约束处理。暗标风险无法排除时输出：`需人工复核（缺：暗标身份信息排查）`。

| 线索类型 | 典型内容 | 风险 | 默认动作 |
|---|---|---|---|
| 企业身份 | 企业名称、简称、Logo、商标、信用代码、资质编号 | P0 | 删除或替换为投标人 |
| 人员身份 | 姓名、证书编号、联系方式、地址、邮箱、网址 | P0 | 删除或按规则脱敏 |
| 业绩奖项 | 项目名称、荣誉、类似业绩、专属工法 | P0 | 暗标技术正文不出现 |
| 地域线索 | 企业所在地、独有基地、固定供应商 | P1 | 删除或泛化 |
| 文件元数据 | 作者、公司、修订者、模板路径、批注人 | P0 | 清理元数据并人工复核 |
| 图片水印 | logo、水印、铭牌、工牌、车牌、图签 | P0 | 替换、模糊或删除 |
| 页眉页脚 | 企业名、内部编号、联系方式、专属口号 | P0 | 删除 |
| 语言习惯 | 我公司、本公司、我单位、我司 | P1 | 改为投标人、承包人、项目部 |

## 雷同与模板残留控制

必须检查：

1. 其他项目名称、道路名、河道名、楼栋号、单位名称。
2. 与市政给排水厂站不符的工序。
3. 重复段落、无项目特征的通用套话。
4. 同错、异常一致、格式异常。
5. 企业宣传口径。

降低雷同风险：用项目部位替代通用对象；用评分项原文重构标题；用本项目工期、场地、界面、专业和风险组织章节；用表格压缩通用描述；删除无法支撑评分的套话。

## 关键词增强命中雷达

关键词命中不是统计词频，而是检查关键词是否落在高权重、可评分、可溯源的位置。每轮审校必须扫描章节标题、节点名称、工序说明、控制措施、参数标准、检查验收、风险应对、资料留痕、评标映射和输出模板示例。

| 扫描域 | 必查关键词类别 | 合格判断 | 不合格修正 |
|---|---|---|---|
| 章节标题 | 评分关键词、行业关键词、验收关键词 | 标题能直接对应评分项和工程对象 | 改为“评分项 + 工程对象 + 验收闭环” |
| 节点名称 | 工艺关键词、重难点关键词、风险关键词 | 节点可被抽取为关键工序 | 补工序对象，如池体抗渗、试压闭水、SCADA 联调 |
| 工序说明 | 问题、措施、参数、验收、证据 | 有可执行步骤、检查频次和责任主体 | 按四步闭环重写 |
| 控制措施 | 质量、安全、绿色、智慧建造关键词 | 措施落到岗位、资源、参数和记录 | 补质检员、安全员、施工员、厂家、自控负责人等主体 |
| 参数标准 | 质量标准、检查频次、准出条件 | 参数来源清楚，缺资料标注需补充 | 改为招标/图纸/规范依据或 A_pending |
| 检查验收 | 验收关键词、检测关键词 | 有检验批、隐蔽验收、试验检测、调试测试 | 补验收方法和不合格整改复核 |
| 风险应对 | 风险关键词、闭环关键词 | 有触发条件、处置措施、关闭证据 | 补风险闭环、整改复核、动态优化 |
| 资料留痕 | 证据留痕关键词 | 有资料名称、章节页码、证明范围、释放等级 | 补证据锚点表或降级表达 |
| 评标映射 | 满分关键词、同义近义表达 | 能解释完整性、针对性、可实施性、可核验 | 补高分理由或反向补写文本 |

## 项目级关键词覆盖矩阵验收雷达

新项目资料包录入后，必须先生成项目级关键词覆盖矩阵，再进入施组正文生成、审查评分和青天类人评标模拟。

| 验收项 | 必达条件 | 失败动作 |
|---|---|---|
| 矩阵生成 | 上传任一触发资料后生成结构化矩阵 | 暂停正文生成，提示需补充提取 |
| 评分项识别 | 评标办法和评分标准中的评分项、分值、扣分项标记为最高权重 | 反向补评分关键词 |
| 答疑覆盖 | 答疑澄清、补遗变更覆盖原招标旧关键词并标记高优先级 | 禁止继续引用旧内容 |
| 清单对象 | 工程量清单主要子目进入工程对象关键词 | 补具体工程对象，删除泛化对象 |
| 图纸参数 | 材料、结构、断面、参数进入材料与参数关键词 | 补参数来源和页码条款 |
| 施组调用 | 生成章节调用矩阵关键词 | 补章节映射和推荐写入方式 |
| 空泛词过滤 | 高度重视、科学组织、确保顺利、加强管理等不得提升为高权重 | 降权或剔除 |
| 来源追溯 | 每个关键词有来源文件、页码或条款号 | 补证据锚点或降级为需补充 |
| 兼容性 | 不影响既有 KG、项目分类、施组生成和审查评分 | 回退新增模块或人工复核 |
| 敏感文件 | 不输出 .env、Token、Cookie、Authorization、AppSecret、SSH key、数据库、日志、缓存 | 删除并复查 |

## 青天类人评标模拟器

模拟评审只用于找缺口和修正文本，不得伪造真实得分。

| 维度 | 目标 | 主要检查 | 不达标动作 |
|---|---:|---|---|
| 评分项覆盖 | 100% | 每个评分项有章节和证据 | 反向补写 |
| 关键词命中 | 100% 关键项命中 | 标题、段首、表格、验收、证据锚点是否有关键词 | 改标题、段首句、表格字段和证据锚点 |
| 关键词权重 | 高权重位置全覆盖 | 标题、评分点、证据留痕是否出现核心关键词 | 将关键词前移到标题、评分矩阵和证据锚点 |
| 关键词分布 | 关键段落均衡分布 | 工序说明、控制措施、参数标准、检查验收、风险应对是否均衡 | 按问题—措施—参数—验收—证据重写 |
| 项目针对性 | 关键章节 100% | 是否出现厂站对象、设备、自控、接口 | 补工程对象 |
| 四步闭环 | 重要段落 100% | 目标、风险、措施、验证 | 闭环重写 |
| 证据锚点 | 关键结论 100% | 资料、章节、页码、证明范围 | 需补充或降级 |
| 暗标安全 | P0=0 | 身份、业绩、元数据、水印 | 删除或复核 |
| 语言密度 | 套话=0 | 空泛表达、绝对承诺 | 动作化改写 |
| 风险准出 | P0=0，P1 有关闭动作 | 否决、响应性、接口、完成态 | 暂停准出 |

## 评分预测字段

| 字段 | 含义 |
|---|---|
| score_item | 评分项名称 |
| max_score | 分值 |
| keyword_layer | 评分、行业、工艺、重难点、风险、质量、安全、绿色、智慧、验收、证据留痕、同义词 |
| keyword_weight_positions | 标题、评分点、工艺流程、验收标准、证据留痕、普通描述的命中情况 |
| keyword_density_quality | 高频但不生硬、密集但不堆砌、专业但不空泛的分布评价 |
| response_sections | 对应章节 |
| evidence_density | 证据密度 |
| project_specificity | 项目针对性 |
| constructability | 可实施性 |
| process_traceability | 问题—措施—参数—验收—证据链完整性 |
| compliance_risk | 合规风险 |
| dark_bid_risk | 暗标风险 |
| similarity_risk | 雷同风险 |
| expected_score_band | 预计得分区间，仅内部修正 |
| repair_action | 修正动作 |

## 评分项反向补写

发现问题后必须直接给可插入文本，不只提示风险。

| 问题 | 补写动作 | 输出形式 |
|---|---|---|
| 评分项漏项 | 新增章节或表格行 | 标题 + 四步闭环正文 |
| 关键词未命中 | 在标题、段首、表格字段、验收和证据锚点补关键词 | 替换段首句 + 证据锚点表行 |
| 关键词权重偏低 | 将普通描述中的关键词前移到章节标题、评分矩阵和证据留痕 | 标题替换 + 矩阵补行 |
| 关键词堆砌 | 删除无措施支撑的重复词，改为问题—措施—参数—验收—证据 | 闭环重写段 |
| 工程对象泛化 | 加厂站构筑物、设备、管网、自控、接口 | 对象化改写 |
| 缺验证检查 | 补检验批、试验、调试、验收、检查频次和整改复核 | 验证检查段 |
| 缺证据锚点 | 补需补充锚点、释放等级、证明范围和留痕资料 | 证据锚点表行 |
| P0/P1 风险 | 删除、降级、补证或人工复核 | 风险整改表 |

## 反向补写关键词模板

```text
【标题】“【评分项关键词】：【工程对象/工序节点】控制、验收与证据留痕”
【段首】本节响应“【评分项原文】”，针对【行业对象】在【关键工序】中存在的【风险关键词】，
由【责任主体】按【工艺流程】控制【参数标准/检查频次】，通过【验收方法】形成【证据留痕资料】，
不合格项执行【整改复核/风险闭环/动态优化】。
【锚点】资料名称：【检测报告/隐蔽验收/旁站记录/调试记录/影像资料】；证明范围：【质量/安全/环保/调试/移交】；释放等级：【R0-R5】。
```

## 四轮自检

输出正式文本前必须完成：

| 自检 | 检查内容 | 输出 |
|---|---|---|
| 初步评审自检 | 否决项、漏项、矛盾、格式、暗标 | 风险和修正 |
| AI 抽取自检 | 标题、关键词、响应句、章节锚点、证据链、权重位置 | 抽取弱项 |
| 高分理由自检 | 完整性、针对性、可实施性 | 补强理由 |
| 雷同风险自检 | 模板化、其他项目残留、异常一致、套话 | 删除或改写 |

发现风险时，先修正，再输出正式文本。

## 最终交付模式

| 输出块 | 内容 |
|---|---|
| 资料分级表 | A_primary、A_secondary、A_pending 和缺口 |
| 评分响应矩阵 | 评分项、关键词增强层、权重位置、章节、证据、风险 |
| 施组母版正文 | 按评分项和问题—措施—参数—验收—证据生成 |
| 评标模拟表 | 覆盖、关键词权重、证据、针对性、可实施性、风险 |
| 暗标雷达表 | 身份、元数据、水印、页眉页脚、残留 |
| 关键词增强雷达表 | 评分、行业、工艺、重难点、风险、质量、安全、绿色、智慧、验收、证据留痕、同义词 |
| 反向补写表 | 漏项、弱项、关键词低权重位置、插入位置、补写文本 |
| 一键体检表 | 已满足、需补证、人工复核、准出状态 |

## 提交前一键体检

| 检查域 | 必达条件 | 准出失败动作 |
|---|---|---|
| 资料分级 | 已区分 A_primary/A_secondary/A_pending | 补资料或提示缺口 |
| 评分覆盖 | 正式评分项 100% 响应 | 补写漏项 |
| 关键词增强层 | 评分、行业、工艺、重难点、风险、质量、安全、绿色、智慧、验收、证据留痕、同义词已覆盖 | 按关键词增强雷达补齐 |
| 关键词权重 | 标题、评分点、证据留痕为高权重命中 | 将关键词前移到高权重位置 |
| 章节母版 | 目录与评分项映射完整 | 调整结构 |
| 四步闭环 | 关键段落目标、风险、措施、验证齐全 | 闭环重写 |
| 参数标准 | 控制目标、质量标准、检查频次、责任主体、验收方法清楚 | 补参数或标注需补充 |
| 证据锚点 | 关键结论有锚点或需补充 | 降级表达 |
| 暗标雷达 | P0 身份线索清零 | 删除或复核 |
| 语言护栏 | 禁用套话和越权承诺清零 | 动作化改写 |
| 完成态释放 | R0-R3 不出现完成态 | 改为拟实施 |
| 接口冲突 | P1 接口风险有关闭动作 | 建责任矩阵 |
| 自动复检 | 整改后复检通过或列人工复核 | 输出准出结论 |

## 准出状态

| 状态 | 条件 |
|---|---|
| QT-GO | P0=0，评分项全覆盖，P1 有关闭动作，可进入人工终审 |
| QT-HOLD | 存在 P0 或关键 A_pending 未提示，暂停定稿 |
| QT-REWRITE | 套话、泛化、缺闭环较多，进入补写 |
| QT-REVIEW | 规则冲突、暗标、平台授权或法定责任不明，人工复核 |

## 最终底线

终稿必须运行评标模拟器和暗标雷达。P0 未清零、暗标身份线索未处理、完成态越权未降级、关键 A_pending 未提示时，不得输出 QT-GO 或“可提交”结论。
