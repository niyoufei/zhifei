# 青天AI评标规则与医院房建评分项

用途：上传到 GPT Knowledge，作为青天大模型类人评标的医院专项房建施工组织设计规则库。

使用原则：
- 遇到技术标编制、评审模拟、缺项检查、满分理由生成，优先检索本文件。
- 本文件定义评分项、满分条件、0分条件、初步评审风险、反雷同规则和证据卡字段。
- 具体医院工程节点与做法到 `02_医院专项房建知识图谱节点卡片库.md` 检索；条款、表格、章节到 `03_医院房建条款证据与模板索引.md` 检索。

重要边界：
- 本文件中的评分项名称、分值和满分条件来自医院房建施工组织设计的通用评标口径。新项目的招标文件、评标办法、答疑补遗与交易系统规则优先级更高。
- 当新项目评分项、分值、评分区间或否决条款不同，必须先重建评分响应矩阵，再引用本文件的“满分响应单元”和“风险规则”作为方法论。
- 不得用本文件替代招标文件原文，不得据此承诺确定满分。
- 不得迁移任何其他项目的工程名称、地块名、楼栋号、床位数、设备型号、接口参数、页码或招标编号。

## AI评标链路

1. 解析招标文件评审项。
2. 提取投标文件响应要素。
3. 对投标文件进行溯源解析。
4. 形成 AI 类人评审逻辑论述。
5. 给出 AI 类人评审建议或直接判分。
6. 输出缺项、弱项、矛盾项、暗标、雷同、OCR错字、医疗专项证据不足风险。

## 满分响应单元

每个评分项正文都按以下结构组织：评分项标题 + 响应结论 + 医院项目依据 + 具体措施 + 资源保障 + 验收标准 + 风险闭环 + 溯源位置。

必备证据字段：评分项原文或同义标题、直接响应结论、医院项目特征证据、医疗/房建工程对象、施工措施与工艺流程、资源配置、质量安全进度环保控制点、专项检测或验收标准、风险及应急闭环、可溯源位置。

工程化句式要求：凡出现“高度重视、全面加强、精心组织、严格执行、确保到位、按规范施工”等空泛表述，自动改写为“对象+部位+措施+频次+标准+记录”；无法补足项目证据时写“需补充（缺：××）”。

青天AI关键词增强要求：每个满分响应单元必须同步输出 `评分关键词、行业关键词、工艺关键词、重难点关键词、风险关键词、质量控制关键词、安全控制关键词、绿色施工关键词、智慧建造关键词、验收关键词、证据留痕关键词、同义词/近义词/评标常用表达词`。关键词不得单独堆砌，应嵌入“评分项标题、响应结论、关键工序、控制目标、参数标准、检查频次、验收方法、责任主体、留痕资料、风险闭环、整改复核、动态优化”等可抽取表达。

说明：本层服务“青天大模型AI类人评标”的检索、抽取和类人判断。关键词只作为 `A_secondary` 召回和表达增强，不替代招标文件、评标办法、图纸、专项设计或正式规范。命中同义词后必须回到项目原文确认，未在项目资料出现的系统、参数、科室、设备或品牌不得写成项目事实。

## 关键词动态增强规则（Project Keyword Dynamic Enhancement Rule）

规则定位：当系统录入新的项目资料包时，知识图谱不得只调用通用行业知识，必须先读取该项目的招标文件、答疑澄清、补遗变更、工程量清单、图纸、设计说明、勘察资料、现场踏勘、技术标准和评标办法，动态生成“项目级关键词覆盖矩阵”。该矩阵用于后续施工组织设计自动编制、内容审查、AI评标匹配和得分优化。

### 触发条件

| 触发资料 | 触发动作 | 证据等级 |
|---|---|---|
| 招标文件 | 提取项目基础信息、招标范围、技术条款、合同目标和初始评分关键词 | A_primary |
| 答疑、澄清、补遗、变更 | 覆盖被修改的评分标准、清单子目、工期、资格、材料、技术参数或报价要求，标记高优先级关键词 | A_primary_override |
| 工程量清单 | 提取主要工程对象、子目名称、工程量、材料规格、措施项目和计价边界 | A_primary |
| 图纸、设计说明、勘察资料 | 提取结构参数、材料规格、断面尺寸、施工范围、地质水文和技术参数 | A_primary |
| 现场踏勘图片、踏勘记录 | 提取施工条件、交通组织、周边环境、临水临电、村庄农田保护、既有管线和风险点 | A_secondary/A_primary按资料来源确认 |
| 技术标准和要求 | 提取强制性要求、检测指标、验收方法、材料性能和资料归档要求 | A_primary |
| 评标办法或评分标准 | 提取评分项、分值、扣分项、页数限制、AI辅助评审要求和技术标响应重点 | A_primary |

### 动态关键词权重

| 来源或内容 | 权重等级 | 处理规则 |
|---|---|---|
| 答疑澄清、补遗变更中出现的关键词 | 最高权重 | 覆盖原招标文件旧关键词，禁止继续引用被替代内容 |
| 评分标准中的评分项和扣分项 | 最高权重 | 必须进入评分响应矩阵和对应评分章节 |
| 招标范围和工程量清单中的主要工程对象 | 高权重 | 至少出现在工程概况、重难点、施工方案、质量/安全/进度/总平面之一 |
| 图纸中的结构参数、材料规格、断面尺寸、施工范围 | 高权重 | 写入参数标准、工艺控制和验收检测 |
| 技术标准和合同条款中的强制性要求 | 高权重 | 写入质量、安全、环保、验收和风险闭环 |
| 现场踏勘资料反映的施工条件、风险点、交通条件、周边环境 | 中高权重 | 写入总平面、风险控制、环保水保和施工部署 |

### 施组编制调用规则

1. 每个评分章节必须覆盖对应评分关键词。
2. 每个主要工程对象必须至少出现在工程概况、重点难点、施工方案、质量控制、安全控制、进度组织或总平面布置中。
3. 关键施工工艺必须写成“工序流程+操作措施+质量控制+验收标准+留痕资料”。
4. 风险关键词必须写成“风险识别+应对措施+检查频次+责任人+留痕资料”。
5. 材料和参数关键词必须写入材料控制、工艺控制或质量验收内容。
6. 答疑澄清关键词必须优先覆盖，禁止继续引用被澄清替代的旧内容。
7. 不得机械堆砌关键词，应将关键词自然嵌入施工措施、技术参数、检查动作和验收标准中。
8. 对青天大模型AI类人评标重点关注内容，强化项目对应性、评分项覆盖、参数化表达、工艺闭环、质量安全环保留痕。

验收目标：评分项全覆盖，项目名称、工程部位、清单子目、图纸参数一致；施工措施具体、可执行、可检查；风险识别对应现场；质量、安全、环保、进度有量化指标；关键措施均有验收标准和资料留痕；避免通用模板化、空泛化和其他项目残留。

## 技术评分项

### HOSP-SCORE-01-CONSTRUCTION-METHODS 施工方案和技术措施

- 分值：4
- 评分标准：方案和措施合理、科学、有针对性；危险性较大的分部分项工程专项方案计划全面。
- 匹配章节：H-S-06 至 H-S-14；H-P-01 至 H-P-18
- 关键词：施工方案；技术措施；医疗工艺；地基基础；主体结构；洁净工程；医用气体；放射防护；专项机电；危大工程
- 满分条件：
  - 覆盖地基基础、主体结构、医疗工艺流线、洁净与感控、医用气体、放射防护、专项机电、装饰装修、医疗环保和专项验收等主要对象。
  - 每个关键工序具备项目依据、工艺流程、参数控制、资源保障、质量安全控制和验收资料。
  - 危大工程具备专项方案计划、审批/论证、交底、监测、旁站、验收和停复工条件。
  - 医院专项工程具备深化确认、样板先行、检测验收、试运行和移交培训闭环。
- 0分/否决风险：
  - 无相应施工方案及措施。
  - 明显不合理或与医疗功能、结构形式、工期、现场条件矛盾。
  - 把医院项目写成非医疗通用建筑工程，缺少医疗工艺、洁净、医气、放射防护等关键专项。
- 写作指令：正文必须能让 AI 抽取到医院工程对象、措施、资源、验收标准和风险闭环。

### HOSP-SCORE-02-QUALITY 质量保证措施

- 分值：2
- 评分标准：质量保证体系完备，技术和工艺先进，质量保证措施得当且有针对性。
- 匹配章节：H-S-15；H-S-18；H-P-19
- 关键词：质量；GB50300；检验批；隐蔽验收；洁净检测；医用气体试验；放射防护检测；消防验收；竣工资料
- 满分条件：
  - 质量体系、三检制、样板引路、材料报验复试、隐蔽验收、检验批、分项分部验收和整改复验闭合。
  - GB50300及医疗专项验收要求已绑定到工序控制点、检验方式、频次和资料成果。
  - 洁净工程、医用气体、放射防护、消防、智能化、医疗设备配套均有专项检测或调试验收资料。
- 0分/否决风险：
  - 无质量保证措施。
  - 仅有口号，无工序对象、检验标准、专项检测和资料成果。
- 写作指令：质量措施必须从“工序控制”落到“检验批/隐蔽/检测/复验/专项验收资料”。

### HOSP-SCORE-03-EXCELLENCE 创优方案

- 分值：2
- 评分标准：有创优承诺，创优方案完整，措施得当且有针对性，投入有保障。
- 匹配章节：H-S-15；H-P-19
- 关键词：创优；医疗工艺样板；洁净样板间；医气末端样板；放射防护样板；机电管综；实测实量；资料同步
- 满分条件：
  - 创优目标、样板引路、首件验收、实体实测、观感提升和资料同步成体系。
  - 样板覆盖门诊公共区、病房、护士站、洁净手术室、ICU、医气末端、放射防护房间、机房和管井等医院关键界面。
  - 投入保障对应深化设计、试验检测、质量通病防治、专项检测和整改闭环。

## 初步评审与风险规则

### PRE-HOSP-001 评分项覆盖完整性

- 风险等级：reject_or_zero_risk
- 检查规则：每个HOSP-SCORE评分项至少有一个章节锚点、响应句和证据模板。

### PRE-HOSP-002 工期质量安全目标一致性

- 风险等级：reject_risk
- 检查规则：工期、质量、安全、文明、环保、绿色施工、创优、专项验收、试运行和移交目标不得与招标文件冲突。

### PRE-HOSP-003 项目身份与医疗工程指纹一致性

- 风险等级：reject_risk
- 检查规则：项目名称、招标编号、建设地点、建筑面积、层数、高度、结构形式、医疗功能、床位数、科室规模、关键参数不得出现其他项目残留。

### PRE-HOSP-004 暗标身份信息检测

- 风险等级：reject_or_deduction_risk
- 检查规则：暗标技术文件不得出现投标人名称、人员姓名、证书编号、地址电话、Logo、水印、文件属性身份信息、企业荣誉和特定业绩。

### PRE-HOSP-005 雷同与同错检测

- 风险等级：collusion_risk
- 检查规则：专门针对本工程内容不得与其他投标文件高度雷同或出现同错；通用段落须结合本项目医疗功能、部位、频次、标准和记录改写。

### PRE-HOSP-006 OCR证据可信度

- 风险等级：evidence_risk
- 检查规则：OCR来源片段如有识别异常，应保留清洗后文本和原始线索，避免错字进入判分证据。

### PRE-HOSP-007 空话套话工程化改写

- 风险等级：score_deduction_risk
- 检查规则：凡出现空泛表述，必须改写为“对象+部位+措施+频次+标准+记录”；无法补足项目证据时标注“需补充”。

### PRE-HOSP-008 医院专项缺项风险

- 风险等级：score_deduction_or_substantial_risk
- 检查规则：招标文件或图纸出现洁净工程、医用气体、放射防护、医疗废水、智慧医院、物流传输、专项验收时，正文必须有对应章节、检测资料和移交闭环。

## 医院同义词与OCR触发策略

- 触发策略：检索时同时使用“招标原词、行业同义词、常见简称、OCR易错词”，命中后必须回到项目原文确认。
- 关键同义词：洁净工程/净化工程/净化空调；医用气体/医气/中心供氧；消毒供应中心/CSSD/供应室；放射防护/辐射防护/射线防护；负压隔离病房/隔离病房/负压病房；弱电智能化/智慧医院/智能建筑；物流传输/气动物流/箱式物流；医疗废水/污水预处理/污水站。
