## 1A. 关键词动态增强规则（Project Keyword Dynamic Enhancement Rule）

当新项目创建或上传招标文件、答疑澄清、补遗变更、工程量清单、图纸、设计说明、勘察资料、现场踏勘图片或记录、技术标准和要求、评标办法或评分标准任一资料时，自动触发项目级关键词动态增强。知识图谱不得只调用通用行业知识，必须先读取项目资料包并生成“项目级关键词覆盖矩阵”，供施工组织设计自动编制、内容审查、AI 评标匹配和得分优化调用。

### RIV-PROJ-KW-TRIGGER｜触发条件

| 触发资料 | 自动动作 | 优先级 |
|---|---|---|
| 招标文件 | 提取项目基础信息、招标范围、合同条款、技术要求、格式和实质性响应 | P0 |
| 答疑、澄清、补遗、变更文件 | 提取覆盖旧内容的高优先级关键词，覆盖原招标文件旧关键词 | P0-最高 |
| 工程量清单 | 提取主要清单子目、工程对象、工程量、材料和参数 | P0 |
| 图纸、设计说明、勘察资料 | 提取结构参数、材料规格、断面尺寸、施工范围、地质和水文条件 | P1 |
| 现场踏勘图片、踏勘记录 | 提取施工条件、风险点、交通条件、周边环境、村庄农田保护 | P1 |
| 技术标准和要求 | 提取强制性标准、检测指标、验收频次、质量评定要求 | P0 |
| 评标办法或评分标准 | 提取评分项、分值、扣分项、页数限制、AI 辅助评审要求 | P0-最高 |

### RIV-PROJ-KW-WEIGHT｜项目级关键词权重

| 来源或内容 | 权重等级 | 处理规则 |
|---|---|---|
| 答疑澄清、补遗变更中出现的关键词 | 最高权重 | 覆盖原关键词，标记为答疑澄清覆盖关键词 |
| 评分标准中的评分项和扣分项 | 最高权重 | 必须进入评分章节标题、段首响应和证据锚点 |
| 招标范围中的主要工程对象 | 高权重 | 必须进入工程概况、重点难点、施工方案和控制章节 |
| 图纸中的结构参数、材料规格、断面尺寸、施工范围 | 高权重 | 必须进入材料控制、工艺控制或质量验收 |
| 工程量清单中的重点子目和工程量 | 高权重 | 必须绑定工程对象、资源配置、进度组织和验收资料 |
| 技术标准和合同条款中的强制性要求 | 高权重 | 必须进入控制标准、检查频次和验收闭环 |
| 现场踏勘资料中的施工条件、风险点、交通条件、周边环境 | 中高权重 | 必须进入重难点、安全文明、环保和总平面布置 |
| 通用质量、安全、进度、环保管理词 | 普通权重 | 仅作辅助，不替代项目关键词 |
| 高度重视、科学组织、确保顺利、加强管理等空泛口号 | 低权重或剔除 | 不得提升为高权重，不得作为得分支撑 |

优先级固定为：答疑澄清、补遗变更 ＞ 评分办法和评分标准 ＞ 招标范围 ＞ 图纸参数 ＞ 工程量清单 ＞ 技术标准 ＞ 踏勘资料 ＞ 通用行业知识。若来源冲突，以上级来源覆盖下级来源，并保留被覆盖旧词的禁用标记。

### RIV-PROJ-KW-MATRIX｜项目级关键词覆盖矩阵字段

项目资料接收后必须生成结构化矩阵。字段至少包括：关键词、关键词类别、来源文件、来源页码或条款号、对应工程部位、对应施组章节、推荐写入方式、权重等级、风险等级、是否为评分关键词、是否为答疑澄清覆盖关键词、是否必须在技术标正文中出现、建议出现频次、可关联的检测/验收/留痕资料。

### RIV-PROJ-KW-CALL｜施组编制调用规则

1. 每个评分章节必须覆盖对应评分关键词。
2. 每个主要工程对象必须至少出现在工程概况、重点难点、施工方案、质量控制、安全控制、进度组织或总平面布置中。
3. 关键施工工艺必须写成“工序流程 + 操作措施 + 质量控制 + 验收标准 + 留痕资料”。
4. 风险关键词必须写成“风险识别 + 应对措施 + 检查频次 + 责任人 + 留痕资料”。
5. 材料和参数关键词必须写入材料控制、工艺控制或质量验收内容。
6. 答疑澄清关键词必须优先覆盖，禁止继续引用被澄清替代的旧内容。
7. 不得机械堆砌关键词，应将关键词自然嵌入施工措施、技术参数、检查动作和验收标准中。
8. 对青天大模型 AI 类人评标重点关注内容，强化项目对应性、评分项覆盖、参数化表达、工艺闭环、质量安全环保留痕。

## 3A. 模拟评标关键词命中审查表

模拟评标时除检查评分覆盖，还必须检查关键词是否出现在 AI 类人评标的高价值位置。命中率只用于优化识别度，不得替代招标评分办法。

| 审查项 | 检查问题 | 通过标准 | 权重倾向 | 整改动作 |
|---|---|---|---|---|
| 标题命中 | 章节标题是否包含评分关键词和河道工程对象 | 每个评分项至少一个标题可定位 | 高 | 重构目录，增加“清淤疏浚/护岸护坡/排口截污/生态修复”等对象词 |
| 段首响应 | 段首是否引用评分项原文、最高档关键词和响应范围 | 评分项原文不改写，最高档关键词不漏项 | 高 | 段首改为评分响应句 |
| 工序命中 | 工序说明是否包含关键工序、工艺流程和转序条件 | 至少包含问题、措施、参数、验收、证据 | 中高 | 改写为空话段，补工艺链和责任岗位 |
| 参数标准 | 是否写明控制目标、质量标准、检查频次、责任主体 | 参数有依据；无依据写需补充 | 中高 | 补图纸/清单/规范依据，删除编造数值 |
| 风险闭环 | 风险是否形成识别、整改、复核、销项 | P0 风险有关闭动作，不能关闭则标注需人工复核 | 中 | 建 blocker 清单和整改复核表 |
| 验收资料 | 是否有隐蔽验收、检验批、通水验收、调试验收等 | 验收方法、频次、岗位、资料齐全 | 中高 | 补验收闭环表 |
