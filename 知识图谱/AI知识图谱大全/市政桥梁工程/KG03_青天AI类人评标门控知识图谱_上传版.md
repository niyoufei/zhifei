## 评分响应矩阵

正式编制前必须输出：

| 序号 | 评分项原文 | 分值/等级 | 满分关键词 | 同义召回词 | 关键词嵌入位置 | 招标证据 | 项目特征 | 响应章节 | 施工措施 | 资源保障 | 验收闭环 | 证据留痕 | 风险/扣分点 | 修正动作 |
|---|---|---|---|---|---|---|---|---|---|---|---|---|---|---|

规则：评分项原文不得随意改写；每项至少绑定工程对象、措施、资源、验收闭环、证据留痕和风险修正动作；缺证据时写“需补充”。章节标题、评分点、验收标准和证据留痕字段必须优先嵌入满分关键词和同义召回词。

## 满分目标覆盖矩阵

| 评分项原文 | 满分关键词 | 同义召回词 | 关键词类别 | 工程对象 | 四步闭环 | 量化参数/占位 | 证据页族 | 风险点 | 整改动作 | 释放状态 |
|---|---|---|---|---|---|---|---|---|---|---|

释放状态：
1. READY：资料完整、四步闭环完整、无暗标/越权风险。
2. READY_WITH_GAPS：非关键资料缺失但已标注 blocker。
3. BLOCKED：缺评分标准、图纸清单、关键参数、暗标规则或存在身份/完成态风险。
4. MANUAL_REVIEW：涉及废标、异常低价、围串标、法定责任、自动否决、证据冲突。

## 关键词权重规则

青天 AI 类人评标识别优先判断“评分点是否被明确响应、响应是否绑定工程对象、措施是否可实施、验收和证据是否闭环”。关键词权重只用于提升可抽取性，不得替代招标证据、图纸清单和规范要求。

| 出现位置 | 权重等级 | 识别逻辑 | 写作要求 |
|---|---|---|---|
| 章节标题/二级标题/表名 | 高权重 | 标题是 AI 分段和主题识别入口 | 标题中自然出现评分关键词、工程对象和控制主题，如“桩基工程质量控制与隐蔽验收” |
| 评分项原文/评分响应矩阵 | 高权重 | 直接对应评审条款和分值 | 保留评分项原文，补充满分关键词、同义召回词和扣分点 |
| 证据留痕/资料清单 | 高权重 | 判断措施是否可验证、是否有闭环 | 写明检测报告、旁站记录、影像资料、隐蔽验收、整改复核、签认移交 |
| 工艺流程/关键工序 | 中高权重 | 判断方案完整性和专业深度 | 用“工序—责任—参数—检查”表达，不只罗列工艺名称 |
| 验收标准/质量标准 | 中高权重 | 判断质量控制和验收可执行 | 绑定检验批、允许偏差、见证取样、复试报告、验收方法 |
| 风险应对/整改闭环 | 中高权重 | 判断重难点、风险控制和动态优化 | 写清触发条件、责任主体、整改动作、复核关闭 |
| 控制措施/资源保障 | 中权重 | 判断可实施性和组织保障 | 绑定人员、机械、材料、检测资源、检查频次 |
| 输出模板示例 | 中权重 | 影响生成文本的复用表达 | 示例必须包含评分关键词、工程对象、验收和证据 |
| 普通描述/背景介绍 | 低权重 | 对评分贡献弱，易被判套话 | 限制空泛叙述，转化为问题—措施—参数—验收—证据 |

## 关键词动态增强规则

规则名称：关键词动态增强规则（Project Keyword Dynamic Enhancement Rule）。

触发条件：新项目创建，或上传招标文件、答疑澄清、补遗变更、工程量清单、图纸/设计说明/勘察资料、现场踏勘图片/记录、技术标准和要求、评标办法或评分标准任一资料时自动触发。

执行原则：不得只调用通用行业知识，必须优先读取项目资料包，生成“项目级关键词覆盖矩阵”。答疑澄清、补遗变更的优先级高于原招标文件；凡修改评分标准、清单子目、工期、资格、材料、技术参数或报价要求的，自动覆盖旧关键词，并标记“高优先级关键词/答疑澄清覆盖关键词”。

| 提取类别 | 提取内容 | 施组调用要求 |
|---|---|---|
| 项目基础关键词 | 项目名称、标段名称、项目编号、建设地点、招标人、工期、质量目标、合同估算价、最高投标限价、项目类别、标段划分 | 与工程概况、响应承诺、进度目标和初评避险一致 |
| 评分关键词 | 评分项、分值、扣分项、页数限制、AI 辅助评审要求、综合评估法、技术评分合理价格法、施工组织设计、关键线路、施工总平面、质量保证、安全生产、水土保持、环境保护、安全度汛、冬雨季施工、重点难点 | 每个评分章节必须覆盖对应评分关键词，标题和评分响应矩阵高权重出现 |
| 工程对象关键词 | 招标范围、清单、图纸中的具体工程对象和清单子目 | 不得泛化为大类，应写入工程概况、重点难点、施工方案、质量安全、进度或总平面 |
| 施工工艺关键词 | 项目特有施工方法、工艺流程、机械设备、施工顺序、作业面组织、专项工艺、危大工程、关键技术路线 | 写成“工序流程+操作措施+质量控制+验收标准+留痕资料” |
| 材料与参数关键词 | 材料名称、规格型号、技术参数、工程量、强度、厚度、掺量、粒径、密实度、渗透系数、抗压强度、检测标准 | 写入材料控制、工艺控制或质量验收，不得虚构参数 |
| 风险控制关键词 | 临水作业、深基坑、高边坡、地下水、雨季施工、防汛度汛、交通导改、机械转场、临时用电、起重吊装、环保水保、扬尘噪声、村庄农田保护、管线保护 | 写成“风险识别+应对措施+检查频次+责任人+留痕资料” |
| 验收检测关键词 | 测量复核、材料进场验收、见证取样、隐蔽验收、工序验收、单元/分部/单位工程验收、质量评定、检测频次、检测指标、资料归档、影像留痕 | 绑定检测报告、验收记录、整改复核和资料归档 |
| 答疑澄清关键词 | 答疑、澄清、补遗、变更中新增或替代的评分、清单、工期、资格、材料、参数、报价关键词 | 最高权重；禁止继续引用被澄清替代的旧内容 |

项目级关键词覆盖矩阵字段至少包括：关键词、关键词类别、来源文件、来源页码或条款号、对应工程部位、对应施组章节、推荐写入方式、权重等级、风险等级、是否为评分关键词、是否为答疑澄清覆盖关键词、是否必须在技术标正文中出现、建议出现频次、可关联的检测/验收/留痕资料。

| 资料来源/位置 | 权重等级 | 处理规则 |
|---|---|---|
| 答疑澄清、补遗变更中出现的关键词 | 最高权重 | 覆盖原招标文件旧关键词，标记高优先级和覆盖来源 |
| 评分标准中的评分项和扣分项 | 最高权重 | 必须进入评分响应矩阵和技术标正文 |
| 招标范围中的主要工程对象 | 高权重 | 必须进入工程对象、施工方案、质量安全和验收字段 |
| 图纸中的结构参数、材料规格、断面尺寸、施工范围 | 高权重 | 必须进入技术参数、工艺控制和验收标准 |
| 工程量清单中的主要子目和工程量 | 高权重 | 必须进入工程对象绑定表和参数化写作字段 |
| 技术标准和合同条款中的强制性要求 | 高权重 | 必须进入控制标准和初评避险检查 |
| 现场踏勘资料中的施工条件、风险、交通、周边环境 | 中高权重 | 必须进入重难点、风险控制、总平面和安全文明 |
| 通用质量、安全、进度、环保管理词 | 普通权重 | 只能辅助表达，不能替代项目关键词 |
| 空泛口号类词语 | 低权重或剔除 | “高度重视、科学组织、确保顺利、加强管理”等不得提升权重 |

## 工程对象绑定与技术标准校核

| 规则 | 要求 |
|---|---|
| 工程对象绑定表 | 字段包括工程对象、来源文件、页码/条款、清单子目、图纸参数、施工工艺、对应章节、质量控制、安全控制、验收留痕 |
| 参数一致性 | 项目名称、工程部位、清单子目、图纸构造、材料规格、数量和参数必须一致；不一致时输出需人工复核 |
| 参数来源 | 项目资料明确参数时以项目资料为准；资料未明确且确需补充时优先调用知识库现行规范 |
| 联网校核 | 具备联网能力时检索官方或权威来源确认最新有效标准；无法确认时不得编造 |
| 禁止虚构 | 不得为了专业感虚构厚度、强度、间距、坡度、材料型号、检测频次、验收数值 |
| 行业差异 | 房建、市政道路、市政桥梁、水利水电、管网、园林绿化、高标准农田等模块按招标范围命中释放，禁止跨行业错套 |

## 行业模块释放规则

| 行业模块 | 释放对象 | 不得错套 |
|---|---|---|
| 房建厂房 | 主体结构、屋面防水、装饰装修、机电安装、消防联动、室外配套 | 不作为桥梁、水利、农田默认内容 |
| 市政道路 | 路基、基层、面层、排水、交通组织、管线保护 | 不写房建主体和水利单元验收 |
| 市政桥梁 | 桩基、承台墩台、盖梁、梁体、支座、桥面系、交通导改、危大临时结构 | 不写园林成活率和农田涵闸除非范围包含 |
| 水利水电 | 堤防、护岸、防渗墙、导流、度汛、水保环保、单元工程验收 | 不写桥梁支座和房建消防联动 |
| 管网工程 | 沟槽、支护、降排水、管道安装、闭水试验、回填压实、井室施工 | 不写桥梁梁体和房建屋面 |
| 园林绿化 | 土壤改良、苗木栽植、养护、灌溉、成活率、景观恢复 | 不写结构混凝土验收作为主线 |
| 高标准农田 | 土地平整、灌排沟渠、田间道路、涵闸、泵站、农田防护 | 不写城市桥面系作为主线 |

## 初步评审避险清单

不得出现：
1. 漏写实质性响应。
2. 工期、质量、安全、缺陷责任期、节点目标与招标文件冲突。
3. 项目名称、标段、地点、建设内容错误。
4. 其他项目残留。
5. 暗标身份信息泄露。
6. 页数、字体、目录、图表、签章、上传规则违规。
7. 明显复制、雷同同错、模板套话。
8. 降低设计标准或改变招标要求。
9. 把计划写成已完成、已验收、已投运。

## 暗标门控

暗标输出前检查：

| 风险 | 禁写 | 替代 |
|---|---|---|
| 投标人身份 | 企业名称、简称、商标、logo | 投标人、承包人、项目部 |
| 人员身份 | 姓名、证书编号、联系方式、单位归属 | 岗位职责、组织流程 |
| 企业业绩 | 奖项、类似项目、业主名称 | 通用能力和项目措施 |
| 文件属性 | 作者、公司、路径、批注账号 | 清理元数据后提交 |
| 页眉页脚 | 单位名称、水印、特殊编号 | 按招标格式或空白 |

缺暗标规则时输出：需补充（缺：暗标规则、技术文件格式附件、文件属性要求）。

## 异常低价与自动结论

异常低价不得用“亏本让利、人员闲置、机械闲置、材料自有、类似业绩”解释。缺报价规则时不判断异常低价。
自动推荐、自动否决、无人化评标结论必须有招标、监管平台或试点规则授权；无授权时输出需人工复核。
