# 电力工程知识图谱增强规则引擎

## 文件用途

本文件按照《通用型知识图谱增强指令》对现有电力工程知识图谱进行规则引擎化升级。它补充统一证据等级、节点 Schema、关系边 Schema、通用评分项词库、规则占位节点、四步闭环、语言护栏、冲突处理、机器可读 JSON 和 nodes.csv / edges.csv 导出建议。

本文件属于 Knowledge，可与 `00/01/02/03` 一起上传，用于提升检索、推理、评分、审查、整改、复检和导出能力。

| 继承文件 | 00 总索引、01 工程知识图谱、02 接口专项图谱、03 青天 AI 评标门控 |

证据等级映射:

| 旧等级/来源 | V2 等级 | 使用边界 |
|---|---|---|
| 招标文件、答疑、合同、图纸、清单、评分办法、正式标准、平台正式规则 | A_primary | 需 source、page、clause、original_text 或 evidence；可作强制审查依据 |
| A_governance 且来源为用户指定指令或已上传正式规则 | A_primary | 仅限治理规则本身，不证明项目完成事实 |
| B_primary_composite | A_secondary，除非已补齐正式证据链 | 可支撑综合判断，不得覆盖 A_primary |
| C_rule_composite | A_secondary | 通用经验、写作增强、工艺建议，不得写成强制条款 |
| D_open_issue | A_pending | 必须 source_required=true，输出 input_required 和 upgrade_condition |
| 原生图谱样本、类似项目经验、专家经验词库 | A_secondary | 增强召回和写作，不证明本项目事实 |
| 暗标、页数、格式、签章、平台雷达、AI 自动评审等未上传规则 | A_pending | 不得虚构具体规则，默认需补充或人工复核 |
