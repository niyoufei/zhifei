# 电力工程 V9 素材吸收与清洗补丁

## 文件用途

本文件用于判断并吸收 V9 跨行业 JSON 知识图谱库中对电力工程专属知识图谱有价值的内容。V9 素材只作为 `A_secondary` 通用经验增强依据，主要用于补强关键词、同义词、四新技术候选、数字化交付、智慧工地、绿色低碳、通信接口、储能安全、数据中心供配电、海上风电和进度计划能力。

本文件不得把 V9 中的营销话术、激活字段、竞争性描述、未经证实的效果承诺、加分承诺或身份线索原样导入主图谱。

## 吸收边界

| 项目 | 处理方式 |
|---|---|
| V9 原始 JSON | 可作为 A_secondary 技术候选和词库来源 |
| 原始激活字段 | 禁止导入 |
| 竞争性攻击话术 | 禁止导入 |
| “优于对手”“建议考察对手”等比较性表述 | 禁止导入 |
| 未经项目证明的效果数值、加分承诺、排名表达 | 禁止导入 |
| 技术概念、触发关键词、适用场景 | 可清洗后吸收 |
| 需要项目数据验证的指标 | 转为 A_pending 或 blocker |
| 与招标文件、设计文件冲突的内容 | 由 A_primary 覆盖 |

## 关键词增强 V1.2 清洗附加规则

| 规则 | 控制要求 | 允许嵌入位置 |

## 禁止原样导入清单

| 原始内容类型 | 禁止原因 | 清洗后允许表达 |
|---|---|---|
| 激活词、环境触发字段 | 属于原系统触发逻辑，不是工程知识 | 删除 |
| 竞争性比较字段 | 暗标和合规风险 | 改为中性技术对比，不提对手 |
| 加分、排名、领先等承诺 | 缺评分依据和项目证据 | 改为“可作为四新/数字化候选响应点，需评分项确认” |
| 未经证明的百分比或固定指标 | 缺项目记录和公式变量 | 改为“需补充实测数据/平台记录/试验报告” |
| “承诺 PUE”等确定性结果 | 可能构成无证承诺 | 改为“按招标和运维目标设置能效监测和验证机制” |
| “已实现”“已达标”“已验证” | 完成态越权 | 改为“拟建立、计划实施、形成记录后验证” |
| 夸张营销句 | 技术标审查风险 | 改为对象、措施、标准、记录、闭环 |
